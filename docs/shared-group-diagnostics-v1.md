# 共同协议下的分组更新

使用共同 batch=256 协议的 27 组完整验证预测，三个种子各包含 ID 基线、统计融合、MAKE、统计 + MAKE、逐行为相似度，以及 MUSE 普通聚合/完整组合的 L200/L1000。按训练目标曝光频次、多模态表示覆盖率和非 padding 历史长度分组，不沿用旧 batch=32 分组指标。

入口 `run_group_diagnostics.py` 串行运行三个已存在的分组审计工具，保存状态及模型路径映射摘要。训练频次只从训练曝光统计；多模态表示覆盖、历史长度在检索前定义，重复行为计数，未知 ID 不当作 padding。完整预测须逐行对齐用户、标签、源行。目标多模态表示缺失等小组样本过少时只记录规模，不作可靠优劣结论。

三项分析全部完成，27 组预测的 SHA-256 在三个报告中完全一致。分组 AUC/LogLoss 是描述性指标，没有分组置信区间，不能由组间差异作因果推断。只读验证预测，不训练模型、不评估保留测试集。


## 描述性结果

统计 + MAKE 相对 ID 基线的 AUC 增量，在训练目标曝光频次 0、1、2–5、6–20、21–100、101+ 六组的三种子平均值依次为 +0.022950、+0.021737、+0.016317、+0.012232、+0.006328、−0.000384。对应验证曝光数为 137,978、84,277、170,886、180,136、137,301、58,195。低频组改善更明显，但零训练目标曝光不等于全新商品，高频组也不支持普遍收益。

完整 MUSE 的 L1000 相对 L200，在历史长度 201–500、501–1000 两组的 AUC 增量三种子平均为 +0.003048、+0.003429。后者含 756,252 条曝光，占验证集约 98.37%，总体结果主要反映长历史用户。目标多模态表示缺失仅 13 条曝光，不能据此推断缺失场景效果。
