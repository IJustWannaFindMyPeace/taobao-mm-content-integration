# 共同协议下的分组更新

使用共同 batch=256 协议的 27 组完整验证预测，三个种子各包含 ID 基线、统计融合、MAKE、统计 + MAKE、逐行为相似度，以及 MUSE 普通聚合/完整组合的 L200/L1000。按训练目标曝光频次、内容覆盖率和非 padding 历史长度分组，不沿用旧 batch=32 分组指标。

入口 `run_group_diagnostics.py` 串行运行三个已存在的分组审计工具，保存状态及模型路径映射摘要。训练频次只从训练曝光统计；内容覆盖、历史长度在检索前定义，重复行为计数，未知 ID 不当作 padding。完整预测须逐行对齐用户、标签、源行。目标内容缺失等小组样本过少时只记录规模，不作可靠优劣结论。

本轮已启动，尚未汇总完成。分组 AUC/LogLoss 是描述性指标，没有分组置信区间，不能由组间差异作因果推断。只读验证预测，不训练模型、不评估保留测试集。
