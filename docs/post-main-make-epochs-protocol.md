# MAKE 固定预训练轮数：三种子扩展协议

## 研究问题

在共同下游设置下，预训练 1、3、5 轮是否比论文式零轮更有效，继续增加轮数是否存在稳定收益？本实验补足原单种子曲线，不根据新结果改变轮数网格或主实验选点。

[原论文图 6(c) 与 §6.3.2](https://arxiv.org/html/2407.19467v1)明确零轮是未预训练、参与下游联合优化。本地 P0 使用随机联合分支，P1/P3/P5 使用对应轮次内容分支并冻结接入。正轮冻结是本地适配，比较同时涉及初始化与冻结策略，不能解释为仅改变轮数的纯因果效应。

## 固定设置与复用规则

- 5% 用户队列，种子 42、2026、3407；训练 3,052,475 条、验证 768,773 条曝光，L200。
- 内容预训练沿用原 batch=32、AdamW 学习率 0.001、weight decay=0，五轮完整轨迹；这是既有独立阶段设置，不是为了扩大数据临时降低 batch。
- 下游统一 batch=256、单轮、共同学习率与资源门槛。P0/P1/P3/P5 的额外预训练成本不同，分别记录。
- 种子 42 复用已发布端点与论文式零轮审计。2026、3407 从头训练五轮，并逐预测、逐权重核验前三轮与原三轮轨迹一致。旧检查点没有优化器状态，不采用仅加载模型权重的续训。
- P3 必须来自第 3 轮，不按验证集选择最优轮。2026 原主实验选中第 2 轮，需要另训准确的 P3 下游模型；3407 仅在权重来源一致时复用原 P3。
- 保留随机冻结 P0 作为独立敏感性对照，绝不与论文式随机联合 P0 混称。

先核验轨迹、配置、源文件、完整预测和指标，再计算每种子的 P1/P3/P5 相对随机联合 P0，以及固定冻结分支的相邻轮次比较。采用 2,000 次用户级配对 bootstrap；区间条件于已训练模型和当前队列，不做多重校正，也不代表独立数据集重复实验。

## 执行状态

`run_make_epoch_seed_extension.py` 已完成 2026、3407 的串行补充实验及审计，追加工作实际累计约 2 小时 41 分钟。三种子结果见[完整报告](post-main-make-epochs-results.md)。程序核验原始训练代码指纹，遇到轨迹差异、训练失败或下游资源门槛超限即停止，不自动调整数据或 batch。

只评估验证集，结果不改写原冻结测试表。原单种子结果已被查看，本扩展不能声称未见结果的预注册研究，也不保证复现论文的单调提升趋势。
