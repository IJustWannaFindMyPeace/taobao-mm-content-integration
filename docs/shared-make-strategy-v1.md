# 共同协议下的 MAKE 训练策略诊断

本阶段回答内容知识收益是否来自预训练初始化，以及预训练后冻结是否比继续训练更好。使用既定 5% 队列、seed=42、batch=256、两类学习率 0.001、L200，先进行单种子机制诊断，不宣称三种子策略结论。

## 四组策略

|初始化|内容知识分支冻结|内容知识分支继续训练|
|---|---|---|
|随机|随机冻结（新运行）|随机联合（新运行）|
|预训练|预训练冻结（已有核心 C5，后续审计对齐）|预训练联合（新运行）|

下游四组均一轮，相同主干和预算。预训练使用既有同种子三轮内容分支中验证 GAUC 最高的检查点（并列最早）；校验权重摘要，额外预训练成本单列。共享的是 CTR 内容分支知识，不是重新训练 SCL 编码器。

预定义比较：预训练冻结−随机冻结、预训练联合−随机联合，分别检查初始化；预训练联合−预训练冻结、随机联合−随机冻结，分别检查继续训练。不能只用两个同时改变初始化与冻结状态的模型解释单因素作用，也不能声称匹配了总计算量。

## 多轮 ID 诊断

另运行 ID 基线三轮，保留每轮训练与验证指标、预测和检查点。第一轮须与共同核心 ID 基线做逐预测一致性核验，后两轮才用于判断该协议下继续训练的变化。epochs=3 是本项研究变量，其他共同训练参数不变。即使验证后退，也不能推广成所有 ID 模型只能训练一轮。

## 执行与边界

入口 `run_make_study.py --supplement-only --protocol configs/shared-downstream-protocol-v1.json` 接受共同协议，保留显式诊断轮数，保存配置快照与协议摘要。四组新任务串行执行，训练后检查更新与重载；完整效果结论仍须后续预测审计。

四项任务和完整预测审计均已完成，未读取保留测试集。预训练 P=0/1/3/5 的独立轮数诊断已完成，不由本四组矩阵替代。


## 单种子策略证据

|受控比较|GAUC 差|95% 用户配对区间|
|---|---:|---|
|冻结时：预训练−随机初始化|+0.015702|[0.013583, 0.017940]|
|联合训练时：预训练−随机初始化|+0.003099|[0.001477, 0.004641]|
|随机初始化：联合训练−冻结|+0.013913|[0.012403, 0.015442]|
|预训练初始化：联合训练−冻结|+0.001310|[0.000270, 0.002353]|

四项 GAUC 区间均为正。本种子支持预训练提供更好的初始化，也支持在该配置下继续联合训练，不能宣称冻结必然最佳。这是条件于相同下游一轮预算的比较，预训练的额外计算成本未匹配；不能排除更多总训练量对收益的贡献。

ID 基线验证 GAUC 从第一轮 0.573198 降至第二轮 0.548628、第三轮 0.533880，AUC 和 LogLoss 同向恶化。这是当前模型和优化器的训练诊断，不能推广成所有 ID 模型只应训练一轮。

三轮运行第一轮与原核心 ID 基线逐预测最大绝对误差为 0.0。所有保存轮次的源行、标签、用户及重算指标通过检查，最终预测等于最后一轮预测；公共实现、数据与 MAKE 初始化/冻结开关一致。

八项整体/策略比较各使用 2000 次用户 bootstrap，未作多重校正；条件于固定模型和验证人群，仅一个训练种子。公开[审计明细](../reports/shared-make-strategy-v1-seed42-audit.json)保留全部比较，包括随机冻结相对 ID 基线的跨零结果。新主表仍保留原定核心方案，不因本诊断事后替换为策略赢家；策略结果单列。
