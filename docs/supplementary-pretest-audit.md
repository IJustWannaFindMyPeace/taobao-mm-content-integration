# 追加测试前：设计与执行审计

本审计在新增测试推理之前完成。目标是发现可能导致评估口径不一致、重复执行或结果不可追溯的问题，不是再次声明项目已结束。当前结论：未发现需要重训模型的证据，但测试执行仍有必须完成的门槛。

## 覆盖与比较

73份补充检查点和54份原主模型引用均有对应产物。既有报告中的84项配对，加上两种子固定冻结轮数的6项比较，全部映射成功；另固定3项ID第3轮对原主模型第1轮比较，共93项，不存在无法定位模型的比较。每项核验同一队列、种子、batch、公共宽度与优化器设置；研究轴（长度、轮数、结构、冻结策略）仍按原协议区别解释，不因此宣称所有比较只有一个变量。

9个测试输入文件的SHA-256与原冻结清单完全一致，包括内容表、目标特征/标签/源行、用户映射与历史数组。只核验文件摘要，没有执行新增测试模型或读取新增测试指标。

## 发现、处理与执行门槛

|问题|风险|当前处理|
|---|---|---|
|候选模型清单不等于比较清单|漏比较、看到测试后再挑比较|已形成93项比较契约，最终冻结前核验不变|
|重放报告未包含所有脚本辅助依赖|模型文件不变但分桶/统计代码变化|已记录模型与辅助脚本摘要；最终测试入口须强制核验全部依赖|
|既有配对脚本固定标注 validation|测试数字被错误标为验证证据，或反之|不得原样作为测试报告发布；测试适配入口须显式标注并核验测试输入来源|
|ID第2轮模型权重未保存|拿最终权重或重训模型冒充原第2轮|明确排除第2轮追加测试，保留其验证诊断；第3轮与第1轮照常比较|
|续跑入口缺少单实例锁|同时启动两份任务可能覆盖状态或移动活动目录|本轮仅保留现有一个调度器；测试执行器必须先增加单实例保护和原子完成记录|

已有模型不因上述问题重训；验证重放仍然有价值，继续运行。审计时通过的9份重放均验证了候选清单、检查点、评估器摘要以及逐元素预测一致性。这个数字是审计时点快照，不是实时进度。

## 测试启动条件

1. 73份完整验证重放全部通过；结果行数768,773，逐元素误差为0。
2. 测试入口沿用已验证的前向计算路径；分桶、模型类型、缺失mask及推理模式不能另写一套未经回放的逻辑。
3. 单独冻结追加测试入口、所有依赖、检查点、数据与93项比较；原主冻结文件保持不变。
4. 测试统计报告显式使用test口径；保存的923,211条预测与标签/用户/源行严格对齐，重算指标与报告一致。
5. 单实例、重启续跑和完成产物核验通过；禁止无核验跳过已存在目录，禁止自动放宽误差容限或修改batch。

门槛未全部满足前不启动追加测试。最终结果须同时保留所有配置、种子和失败方向，不能以测试结果重新选择检查点。三种子仍共享同一队列；93项区间未作多重校正，不能称为独立重复或严格确认性检验。

## 已验证的程序约束

三项自动化测试通过：不同种子/数据被拒绝，不同batch被拒绝，明确研究轴允许不同。它们检查公共比较契约，不能替代逐模型数值重放。

本审计没有重新散列73份大权重，权重指纹在候选清点和逐模型重放中核验；没有重新训练，也没有运行新增测试。不能承诺后续绝无运行故障，但可在测试前阻止已识别的口径与来源错误。
