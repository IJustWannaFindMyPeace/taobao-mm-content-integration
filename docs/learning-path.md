每阶段交付五项：问题与假设、关键代码导读、实际运行命令、产物及检查结论、一个理解问题。先给出可运行的小步结果，再解释关键代码，不要求一次读完整仓库。

|阶段|阅读代码/实现|产物|验收|
|---|---|---|---|
|0 环境与样例|CIKM scripts/smoke_train.py、scripts/audit_demo.py|CUDA和demo报告|已通过合成训练；demo不可直接关联|
|1 一致数据子集|待实现extract_subset与data_contract|manifest、词表、覆盖表|标签正确、关联可用、时间边界明确|
