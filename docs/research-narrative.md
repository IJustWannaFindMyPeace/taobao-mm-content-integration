# 从内容表示到长历史兴趣：研究叙事

这两个项目研究同一个问题：给定目标广告与用户过去的行为，怎样利用商品内容提高点击预测？研究分两步展开：先解决内容如何进入推荐模型，再解决内容如何参与长历史的筛选与聚合。

本地证据是TAOBAO-MM固定5%用户队列上的下游适配实验。上游SCL（Semantic-aware Contrastive Learning，语义感知对比学习）向量是给定输入，不是本项目重新训练并验证的成果。主测试与后续追加测试分别标注，不包装成新的独立盲测。

![两个项目的共同框架](../figures/storyline/12-framework.png)

## 1. 为什么引入商品内容？

ID embedding是通过交互学习到的编号向量。低频商品可获得的监督较少；内容向量提供另一种商品关联信息。这里先提出可检验的问题：在相同数据与公共设置下，加入固定内容是否改善下游预测？本研究聚焦固定SCL表示的下游利用。

内容项目比较ID基线、[Vector逐商品内容融合适配](https://github.com/IJustWannaFindMyPeace/taobao-mm-content-integration/blob/main/docs/vector-integration.md)、SimScore逐行为相似度、SimTier相似度分桶统计、MAKE预训练特征及其组合。Vector采用内容投影后与ID/类别表示相加，不是原论文一般拼接结构的原样复刻。五种内容方案相对ID的GAUC差值在三个种子均有正向配对区间，支持内容接入方案的排序收益。训练目标曝光低频组的AUC增量更大，说明内容收益在低频场景更突出；分组结果为描述性分析。

## 2. 内容有用，不意味着随便接入都同样有效

SimScore显式给出目标与历史的匹配分数；SimTier将这些分数转成兴趣分布统计；MAKE（Multimodal Knowledge Extractor，多模态知识提取器）预先学习内容兴趣与中间特征，再提供给下游模型。

![内容集成主结果](../figures/storyline/01-content.png)

本地测试中，ID平均GAUC为0.573708；直接向量为0.577532；SimTier为0.590215；MAKE为0.590055；组合为0.591200；SimScore为0.593142。直接向量的平均LogLoss反而略差于ID，因此“排序改善”和“概率损失改善”必须分别描述。

关键发现是：内容接入方式影响结果，但没有出现论文方案沿着单一路径逐级胜出的情况。SimScore的平均GAUC最高，组合的平均AUC最高；组合对单独SimTier的增量在两个种子跨零。我们支持“有效利用内容”，不复刻“组合必然最佳”的结论。

### 内容接入方式对照

Vector、SimScore 与 SimTier 对应逐商品表示、逐行为关系和整体分布三个信息层级。以下为同一公共协议下的适配比较，前三者是替代接入方案；MAKE进一步学习内容特征，组合方案并行使用MAKE与SimTier。

|方法|内容侧信息|接入位置|主要特点|
|---|---|---|---|
|Vector|每件商品的128维内容向量|投影后加入目标与历史表示|提供完整向量输入，由下游学习利用|
|SimScore|逐历史相似度及有效标记|投影后加入历史表示|显式提供目标关系，保留逐行为对应|
|SimTier|20维相似度分桶计数|预测网络第一层|显式表达频次与分布，压缩逐行为细节|
|MAKE|128维内容兴趣＋32维隐藏特征|预测网络第一层|通过点击监督预训练内容网络，主表冻结接入|
|SimTier＋MAKE|统计与预训练特征|预测网络第一层并行汇合|结合分布统计与学习式兴趣|

|方法|测试AUC ↑|测试GAUC ↑|测试LogLoss ↓|
|---|---:|---:|---:|
|ID基线|0.605518|0.573708|0.391709|
|Vector|0.607706|0.577532|0.391925|
|SimScore|0.617053|0.593142|0.390030|
|SimTier|0.616165|0.590215|0.390417|
|MAKE冻结接入|0.619105|0.590055|0.390042|
|SimTier＋MAKE|0.619468|0.591200|0.390150|

表中为三个训练种子的均值。五种内容方案相对ID均有三种子正向GAUC配对区间。SimScore平均GAUC和LogLoss最佳，组合平均AUC最佳。结论是内容接入有效，显式关系、统计及预训练特征均优于当前直接向量接入；不存在所有指标一致的单一冠军。完整区间见[正式测试报告](final-test-results.md)。

组合相对SimTier的平均ΔGAUC为+0.000985（跨零／正／跨零），相对MAKE为+0.001144（正／正／跨零）。组合有一定平均收益，但互补增量有限。该比较使用冻结MAKE，与后续联合更新实验分开。结构及完整策略结果见[MAKE方法说明](https://github.com/IJustWannaFindMyPeace/taobao-mm-content-integration/blob/main/docs/make-integration.md)。

内容接入形式与训练策略共同影响效果：前三种方案比较信息表达，MAKE进一步研究提前学习及接入后的更新方式。

## 3. 为什么还要研究训练策略？

ID模型继续训练时，在线训练损失下降，而验证损失升高、验证GAUC下降；第3轮相对第1轮的测试GAUC也在三个种子均下降。内容分支的学习曲线不同，因此统一增加训练轮数未必能同时适合两类分支。

这表明当前ID模型继续训练出现过拟合，支持分别设计内容分支与下游模型的训练策略。第2轮用于验证学习曲线，第1、3轮另有测试对照。

MAKE策略实验将“随机/预训练”与“冻结/联合更新”拆开比较。预训练后联合相对随机联合的三个测试区间均正向；预训练后继续联合相对冻结接入也均正向。前者支持初始化收益，后者说明本设置下冻结并非最佳。预训练具有额外成本，不能说它在等计算预算下必胜。

![MAKE训练策略](../figures/storyline/02-make-strategy.png)

进一步检查固定P1/P3/P5端点：预训练更多并未稳定带来更多下游收益。P0随机联合与正轮冻结同时改变初始化和更新策略；必须与保持冻结的端点比较配合解释。这是机制分析，不是为测试寻找最佳轮数。

## 4. 从使用内容，走向用内容选择历史

当候选历史增多，仅把内容提供给最终模型还不够：进入精细分析之前，哪些历史会被保留？MUSE是多模态搜索式长期兴趣建模框架。GSU（General Search Unit，通用搜索单元）按目标相关性选择Top-K行为；ESU（Exact Search Unit，精细搜索单元）对这些行为进一步计算与聚合。

两个项目的联系是问题递进和公共协议衔接，不是将MAKE模块串到MUSE前面。也不能用两项目最终分数之差归因于单一改进。

固定完整ESU、L1000与K50时，内容余弦相对类目、商品ID、商品与类目ID检索均有三种子正向GAUC区间。内容与ID等权余弦融合反而退步。因此，固定内容余弦是本设置下有效且简洁的历史检索方案，等权加入ID相似度没有带来改进。

## 5. 筛选与聚合是两个独立问题

固定内容检索，再分别研究普通目标注意力、SimTier、SA-TA（Semantic-Aware Target Attention，语义感知目标注意力）及其组合。注意力给出历史行为对兴趣聚合的相对贡献；SimTier提供相似度统计，两者不等价。

![聚合消融](../figures/storyline/06-aggregation.png)

L200时，单独加入统计、单独加入语义注意力，相对普通注意力均有三种子正向区间。但在已有统计的基础上再加入语义注意力，三个区间均跨零。结论是两个模块单独有效，但组合没有明确增量。两者都利用内容相似度，信息重叠是合理解释。

“仅长历史统计”仍保留公共ID和短历史分支。不能由该组结果宣称整个推荐模型不需要ID。

## 6. 更长与更复杂，分别带来了什么？

长度实验固定K50，仅扩大GSU候选范围。完整MUSE从50→200、200→500的测试差值均为三种子正向；500→1000为两个跨零、一个正向。说明更多候选历史可以有价值，但最后一段增量较弱且存在种子差异，不能推广成“500最优”或“1000没有作用”。

![长度实验](../figures/storyline/07-history-length.png)

G1两阶段可学习投影检索在三个测试种子均低于原内容余弦。G3共享融合评分一个跨零、两个负向，种子2026明显退步。已有验证行为诊断显示，该种子对内容相似度的条件斜率为负，与内容Top-50重叠仅约0.37%。该诊断揭示了效果下降伴随的检索偏好反转，为复杂检索的不稳定表现提供了行为层面的解释。

DIN、SIM、TWIN、MISS适配用于补充总体比较。原论文六类方法对应的本地适配中，MUSE平均GAUC最高；但额外的TWIN内容检索对照平均GAUC更高。结构与候选并集预算不同，又没有针对这两行的预先固定配对检验，因此不能写成“所有对照均被MUSE显著击败”。

## 7. 我们最终学到了什么？

可支持的主线是：内容提供增量信息；使用方式与训练策略决定收益能否发挥；长历史需要同时研究选择和聚合；增加复杂度或训练时长并不保证改善。

不能支持的扩张是：重现了上游SCL优越性、每个模块都稳定互补、所有复杂检索都无效、全量或十万历史收益已验证。结果不完全重现原论文并不破坏研究，只要把不同设置、观察与未证实解释分开。
