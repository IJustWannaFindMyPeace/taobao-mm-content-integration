# 研究叙事与展示就绪审计

日期：2026-09-25。结论：**既定本地适配研究的核心故事线已形成，当前图表与数据足够制作研究汇报PPT；未发现需要为现有主张补跑的阻断缺口。**这不等于原论文的全部结论均已重现，也不等于差异的因果机制都已解释完毕。

## 本轮审计做了什么？

|角度|检查内容|结果|
|---|---|---|
|论文对照|两篇指定v1的主要集成、检索、聚合、长度、群体与基线实验|逐项区分方向支持、部分一致、趋势不同和未覆盖|
|科学论证|核心主张是否超出实际比较；观察、分析与猜测是否混淆|11条核心主张映射到证据，并明确禁止推论|
|数据与图表|9份来源指纹、186条图表数据、三种子覆盖与划分|通过；图中模型指标、曲线、频次差值、行为诊断均回查原报告|
|统计表达|标准差、配对区间、均值、绝对差是否混用|分别标注；不把误差线当显著性证明，不隐藏负结果|
|视觉与素材|12张图的PNG/SVG、中文标签、局部横轴与页脚说明|24份资产指纹核验通过；检查全部图像并修正拥挤刻度|
|两项目一致性|共享正文、差异分析、素材数据和图像|共享产物一致，机器可读与展示版本对应|
|工程稳定性|此前整体指标/覆盖审计及冻结执行契约|作为前置证据；本轮未改训练代码、检查点或测试选择|

数值核验由独立于绘图逻辑的审计脚本执行；这是不同核验路径，不宣称由独立研究团队完成。可重运行的结果见[结构化审计](../reports/narrative-readiness-audit.json)。图像已人工视觉检查，自动脚本本身不冒充视觉判断。

## 本次整理修正了什么？

- 将研究正文与工程历史分离：README直接进入核心叙事，不再按下载、环境、调参、补跑顺序讲研究。
- 把与原论文不同的结果保留为分析对象：方法排名、预训练轮数、模块互补性均单列，不能用正向主结果掩盖。
- G3的异常种子同时展示效果与最终检索行为；只报告可观察现象，不把最终负斜率断言为训练失败起因。
- 训练曲线分别标注验证/在线训练及两分支不同batch；P0联合与正轮冻结不画成一种纯轮数处理。
- 主测试文档中关于MAKE仍只有验证证据的旧句已更新为追加测试链接；历史报告保留其时点性质。

## 还没有解决的问题

1. SimScore排名变化、组合增量弱的唯一原因尚未定位；信息冗余等是候选解释。
2. G1缺少与G3同等深度的行为诊断；现有实验足以判断本地效果，不足以证明为何失败。
3. 5%用户队列之外的稳定性、受控训练预算比较、完整原始表示与线上效果没有证据。
4. ID第2轮只有验证过程数据，不主张完整逐轮测试趋势；不存在为此补造权重的需要。

这些是明确保留的研究问题，不靠重复静态审计就能解决。若以后把它们升级为新主张，需要预先设计受控实验和合适的评估方案；当前PPT不宣称已回答。

## 是否需要不同角度或多轮审计？

当前已覆盖三个互补角度：实验/指标与可追溯性、论文/科学论证、图表/展示材料。没有发现需要立即再跑一轮同范围审计的依据，也不建议为了“审计次数更多”重复检查不变产物。

后续PPT实际制作完成后，需要一次针对页面的检查：数值转录、图例字号、删减后是否改变结论、演讲顺序与时间。这是新产物的验收，尚未执行。若更换数据、模型、划分或核心主张，再对受影响范围重新审计。
