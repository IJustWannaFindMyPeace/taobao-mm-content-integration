# Vector：逐商品内容融合

## 研究动机与方法

Vector 检验固定商品内容对 ID 推荐模型的增量价值。[CIKM 2024 §6.1.3](https://arxiv.org/html/2407.19467v1#S6.SS1.SSS3)采用内容与 ID embedding 拼接；本项目在统一主干上实现受约束的融合适配（C2），以 ID 基线（C0）为对照。

商品 ID 与类别 embedding 拼接为 32 维表示。固定的 128 维 SCL 向量经 L2 归一化和无偏置线性投影后，与该表示相加：

`x_fused = x_ID + W · normalize(c)`

目标与历史共享投影参数，融合表示同时参与注意力匹配与历史聚合。投影零初始化，在公共参数与输入相同时保持初始基线预测。内容缺失时保留 ID 表示；padding 不参与聚合。实现见 [side_information.py](../src/side_information.py) 与 [c0.py](../src/c0.py)。

该设计等价于对拼接输入施加 `[I, W]` 投影，保持公共主干维度，但比一般可学习拼接投影约束更强，属于本地适配。

## 实验协议

采用固定 5% 用户队列，训练、验证、测试分别为 3,052,475、768,773、923,211 条曝光。历史窗口为 200，短分支为 50；batch 256，下游训练一轮，三个训练种子为 42、2026、3407，共享数据划分。SCL 向量固定，embedding 使用 SparseAdam，其余参数使用 AdamW，学习率均为 0.001，weight decay 为 0。

该对照比较统一数据遍历预算下的表现，不代表各方法独立调优后的性能上限。完整设置与执行依据见[公共协议](../configs/shared-downstream-protocol-v1.json)、[数据划分](sampling-and-splits.md)和[训练入口](../scripts/train_c0.py)。

## 测试结果

以下为三个训练种子的均值，差值为绝对指标变化。

|指标|ID 基线|Vector|差值|
|---|---:|---:|---:|
|AUC ↑|0.605518|0.607706|+0.002188|
|GAUC ↑|0.573708|0.577532|+0.003824|
|LogLoss ↓|0.391709|0.391925|+0.000216|

三个种子的 GAUC 差值均为正，各自 95% 用户配对 bootstrap 区间均高于零。每项重采样 2000 次，区间条件于固定模型与队列；整体多项比较未做多重校正。

证据：[逐模型指标](../reports/final-test-model-metrics.csv) · [配对比较](../reports/final-test-paired-comparisons.csv) · [最终测试报告](final-test-results.md)。

## 分析与局限

Vector 改善了整体与用户内排序，但平均 LogLoss 略差，未获得所有指标的一致改善。排序收益与论文表 3 的方向相容；数据和结构不同，不比较提升幅度是否等同。

结论是直接内容融合能够改善排序，但概率预测损失没有同步改善。该现象说明内容接入方式仍有优化空间；具体比较采用相同公共协议。LogLoss 差异报告为均值变化。

本结果支持在相同协议下继续比较其他内容接入方式，不预设更复杂方案必然更优。早期探索设置与验证结果保留于[阶段记录](stage-14-side-information.md)，不替代本页正式结果。
