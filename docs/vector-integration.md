# Vector：逐商品内容融合

## 研究问题与论文对应

ID 表示依赖交互监督。Vector 对照检验：在公共推荐主干中加入固定商品内容，是否改善点击预测？代码代号为 C2，ID 基线为 C0；“Vector − ID”表示指标差值，不是第三个模型。

[CIKM 2024 §6.1.3](https://arxiv.org/html/2407.19467v1#S6.SS1.SSS3)描述将预训练内容与 ID embedding 拼接。本项目采用内容投影后相加的适配，不能称为原生产网络的原样复刻。

## 实际结构

实现见 [side_information.py](../src/side_information.py) 和 [c0.py](../src/c0.py)。

1. 商品 ID 与类别 embedding 各 16 维，拼成 32 维基础表示。
2. 固定的 128 维 SCL 内容经 L2 归一化，通过无偏置线性层 `Linear(128, 32, bias=False)`。
3. 将 32 维内容补充与基础表示逐元素相加。目标和历史共享该转换层，共 4096 个可学习权重。
4. 融合后的目标、历史分别经过 query、key 转换计算缩放点积注意力。聚合时直接使用融合后的历史作为 value，没有额外 value 投影。因此内容既影响注意力权重，也影响被加权的历史信息。
5. 短分支处理末尾最多 50 个位置，长分支处理当前完整历史窗口；本组正式窗口为 200。两个兴趣向量各 32 维，与十个原始字段 embedding 的 160 维拼接为 224 维，经 `224 → 128 → 64 → 1` 预测网络输出 logit。内容没有替换十个字段的直接输入。

内容投影权重全部零初始化；在公共参数和输入相同的条件下，初始预测与 C0 一致。零初始化不代表冻结，投影可通过下游损失更新。固定 SCL 输入使用 `detach()`，不更新上游编码器或输入向量。内容缺失时补充为零，保留 ID 行为；历史 padding 由有效位置掩码排除。

`x_ID + Wc` 等价于拼接后施加受约束投影 `[I, W]`：ID 部分固定为恒等映射。一般的拼接后投影可以同时学习 ID 与内容的变换，两者表达能力约束不同。当前设计保持公共主干维度，便于受控比较；并非显存所迫的唯一选择，也没有实验证明它优于一般拼接。

## 训练与随机性

正式设置见[公共协议](../configs/shared-downstream-protocol-v1.json)和[数据划分](sampling-and-splits.md)：固定 5% 用户队列，训练 3,052,475、验证 768,773、测试 923,211 条曝光；batch 256，下游一轮，种子 42、2026、3407。embedding 使用 SparseAdam，其他可训练参数使用 AdamW；学习率均为 0.001，weight decay 为 0。训练目标是 batch 平均二元交叉熵（直接输入 logits）。

[train_c0.py](../scripts/train_c0.py) 中 `torch.manual_seed(cfg['seed'])` 控制模型随机初始化；`np.random.default_rng(cfg['seed'])` 配合 `rng.permutation(len(train))` 控制每轮样本顺序与 batch 组成。C0/Vector 无 Dropout，明确置零的参数不随种子改变初始值。三个训练种子共用同一数据划分，不是三次用户抽样。

[user_split.py](../src/user_split.py) 独立使用固定常数 42 做用户抽样、2026 做验证用户划分。数字与训练种子重合不代表训练时重新切分数据。固定种子不保证跨设备、跨软件版本逐位一致。

一轮是完整遍历训练曝光一次，不是只更新一步。统一一轮比较的是同等数据遍历预算下的表现，不是各方法独立调优后的性能上限。[多轮诊断](research-narrative.md)观察到 ID 基线继续训练时训练损失下降、验证泛化退步；不能据此认定 Vector 等所有方法一轮即收敛或最优。充分调优的比较需要另行预定验证早停与预算，不能依据测试集选择停止时机。

## 正式测试结果

以下为三个训练种子的均值，来源为[逐模型指标](../reports/final-test-model-metrics.csv)与[最终测试报告](final-test-results.md)。

|指标|ID 基线|Vector|Vector − ID|
|---|---:|---:|---:|
|AUC ↑|0.605518|0.607706|+0.002188|
|GAUC ↑|0.573708|0.577532|+0.003824|
|LogLoss ↓|0.391709|0.391925|+0.000216|

各训练种子的 GAUC 差值依次为 +0.003186、+0.004166、+0.004119；各自 95% 用户配对 bootstrap 区间均为正。每项 2000 次重采样，条件于固定模型和队列，不涵盖重新抽样并训练的不确定性；整体多项比较未做多重校正。完整区间见[配对结果](../reports/final-test-paired-comparisons.csv)。

GAUC 的 +0.003824 是绝对差值，相对基线约提升 0.667%；若以百分数表示，是增加 0.3824 个百分点。这些都不是线上 CTR 增幅。展示时优先同时给出基线值、新值与绝对差值。

## 分析与结论边界

- 当前 Vector 适配在三个种子上改善排序，平均 LogLoss 略差。种子 42 的 LogLoss 略好，另两个略差；没有在此提供 LogLoss 差值的统计区间，不能宣称显著恶化。
- 排序指标关注正负样本的相对顺序，LogLoss 还关注真实标签获得的概率大小，两者可能方向不同。这解释了现象可以成立，但没有定位本实验的具体误差成因。
- 本对照同时引入内容及转换层，未通过随机内容等对照排除参数容量等因素；也没有单凭总体指标证明收益来自长尾商品或 ID embedding 被修复。
- 投影瓶颈、优化过程等可作为待验证假设，当前没有因果证据指定它们为结果差异的原因。
- 论文表 3 的 Vector 也报告排序收益，方向相容；数据和结构不同，不作幅度等同。该表未报告 Vector 的 LogLoss，不能声称该指标趋势与论文一致或相反。

现有证据支持：直接逐商品内容融合有排序收益，但不是所有指标一致改善。后续比较 SimScore 等接入方式，不预设方案必然逐级胜出。一般拼接投影与当前受约束融合的对照可作为后续设计候选，尚未执行，不属于现有结论。
