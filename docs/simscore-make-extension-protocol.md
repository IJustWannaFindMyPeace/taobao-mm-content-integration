# SimScore + MAKE 追加实验协议

本实验在已查看既有测试结果后提出，单独报告，不覆盖原主实验，不视为新的盲测。

## 研究问题

单独 SimScore 的平均测试 GAUC 高于 SimTier。检验在 SimScore 上加入预训练 MAKE 特征是否还能带来增量，并与既有 SimTier + MAKE 比较。

## 固定设计

- 同一 5% 用户队列、历史长度200、短历史50、batch256、单轮、种子42/2026/3407。
- 保留既有 SimScore 的逐行为相似度和可用性侧信息，加入冻结 MAKE 的兴趣与隐藏特征；以无偏置线性层加入预测网络第一层，投影零初始化。
- MAKE 复用原各种子按验证 GAUC 选择的预训练检查点，分别为第3/2/3轮，不重新选点或预训练；旧点击输出头不用于下游。
- 主要比较：组合 vs SimScore。次要比较：组合 vs MAKE、SimTier + MAKE、ID。
- 三种子完成训练并冻结模型后评估测试集；AUC、GAUC、LogLoss全部报告。按用户配对bootstrap2000次，固定重采样种子2026，不做多重比较校正。
- 不因测试结果改变超参数、训练轮次或选择种子。新结果不用于改写原冻结实验。

## 验证与状态

实现新增独立模型及训练入口，原训练入口与既有模型文件未修改。必须通过零投影与SimScore等价、投影梯度、MAKE冻结、缺失输入及保存重载检查后才能训练。

数值审计、三种子训练和全部测试配对比较已完成，见[结果报告](simscore-make-extension-results.md)。
