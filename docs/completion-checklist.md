## 必须补齐的有限工作

1. **长度敏感性**：seed=42 补普通聚合和完整组合的 L50/L500，共四组；结合已审计 L200/L1000，只改变 L、固定 K=50。四组已启动。单种子曲线只作诊断，不冒充多种子长度全扫描。
2. **MAKE 训练策略**：旧 batch=32 的随机/预训练 × 冻结/联合对照和多轮曲线保留，但不能混入新协议主表。新协议下补随机冻结、随机联合、预训练联合；预训练冻结复用同种子核心结果。补同协议 ID 多轮曲线，内容预训练继续单独记录既有协议。先做 seed=42 机制诊断；若结论只获单种子支持就明确限定，不将它称为三种子策略结论。
3. **预训练轮数**：冻结接入策略固定，补 P=0/1/3/5 对照。P0 为随机冻结，P1/P3 使用对应轮权重；P5 需要实际完整训练。核心模型既定的验证选点不因轮数诊断被事后改写。若重新训练五轮，须检查前三轮与已有训练的兼容性，不把仅加载权重续训当作优化器状态连续恢复。
4. **共同协议分组与结果汇总**：已有频次/覆盖率/历史长度分组主要对应旧协议，须复用新完整预测更新关键比较，保留样本量及小组不确定性。当前目标内容缺失组仅 13 条，不作可靠优劣结论。
5. **最终只读评估与冻结**：实现不建优化器的评估入口，先回放验证集，核对保存预测和指标；冻结主表模型/种子、配置、代码、数据清单、权重摘要及主比较，再读取完整保留测试集。不能只选验证集赢家，也不以测试结果反馈调参。测试尚未评估。

## 可选或明确受限的范围

- 原始 DIN、原始 SIM 完整结构、TWIN、MISS、复杂可学习 GSU 尚未完整实现，不纳入“已复现”清单。本轮主故事线采用已验证公共主干对照；若不追加专项规格与运行，最终只能限制结论，不能宣称已证明复杂检索无用。
- 缺原始图文、搜索购买监督及替代内容表示，SCL 编码器重训、OpenCLIP/I2I 表示对照和工业线上收益无法由当前下游实验替代。
- 跨项目完整模型差异不止一个模块。概念衔接与共享评估成立，但两个项目最佳数值之差不是单变量升级收益。
- 不为扩充实验数量再扩大 batch/学习率搜索，或重新搜索最大可用用户比例。若出现真实实现错误或资源失败，保存记录并修正受影响范围。
