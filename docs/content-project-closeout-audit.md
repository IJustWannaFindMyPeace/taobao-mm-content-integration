1. `final-storyline.md` 与 `completion-checklist.md` 明确标为历史归档，指向当前研究正文和追加结果，避免将单种子、仅验证等旧描述当成最终范围。
2. 展示计划区分“两项目18页联合蓝图”与“第一个项目19页实际展示稿”。正文16页、附录3页；设计时长约15分钟，实际时长仍须演练确认。
3. 公共协议的 `test_evaluated=false` 解释为冻结时状态，不修改原配置及其指纹；当前完成情况由正式结果报告判定。
4. 覆盖表更新MAKE零轮对照说明：随机联合与随机冻结分开；轮数比较采用同一轨迹的冻结P1/P3/P5。完成状态不再以早期阶段日志为准。

本轮没有修改模型代码、训练配置、权重或原始结果，没有用测试集重新选模型。

## 保留的研究结论

五种多模态接入方案相对ID均改善测试GAUC；SimScore的平均GAUC与LogLoss最好，组合的平均AUC最好。MAKE策略对照支持预训练及接入后的联合更新，更多预训练和模块组合未带来持续增益。低频商品分组表现支持稀疏交互场景的动机。

上述结论针对固定5%用户队列、三个种子及本地适配。组合增量有限与信息重叠相容，但未证明唯一原因；该问题不是当前主线的完成阻断项。主测试之后的追加测试与事后分组继续单独标注。
