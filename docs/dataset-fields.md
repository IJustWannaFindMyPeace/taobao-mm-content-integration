# TAOBAO-MM 字段字典与模型输入

依据：[TAOBAO-MM 官网字段说明](https://taobao-mm.github.io/#dataset-description)，核对日期：2026-09-28。字段语义与匿名取值应分开理解：官方公开了字段含义，但不能由匿名编号直接还原具体年龄、城市名称等原始值。

## 非序列字段

两个项目的 `src/feature_store.py` 使用相同的 `FIELDS` 顺序。每条曝光的 `features` 包含六个用户字段与四个目标商品字段；列位置从 0 开始。

|列位置|字段|官方含义|所属对象|
|---:|---|---|---|
|0|`129_1`|用户 ID|用户|
|1|`130_1`|用户年龄|用户|
|2|`130_2`|用户性别|用户|
|3|`130_3`|用户省份|用户|
|4|`130_4`|用户城市|用户|
|5|`130_5`|用户城市等级|用户|
|6|`205`|商品 ID|目标商品|
|7|`206`|商品类目|目标商品|
|8|`213`|商品城市|目标商品|
|9|`214`|商品省份|目标商品|

每个字段有独立的 ID 词表与 embedding 表。批大小为 B 时，`features` 形状为 `[B,10]`；每个字段查表得到 `[B,16]`，十个字段拼接为 `[B,160]`。年龄等字段在当前模型中也作为离散 ID 查表，不将匿名编号作为连续年龄数值输入。

## 历史、标签与内容字段

|字段|官方含义|本地使用|
|---|---|---|
|`150_2_180`|用户交互商品 ID 序列|历史商品；与目标商品共用 `205` 的 ID 词表和 embedding 表|
|`151_2_180`|用户交互商品类目序列|历史类目；与目标类目共用 `206` 的 ID 词表和 embedding 表|
|`label_0`|点击 one-hot 标签|`[1,0]` 为未点击，`[0,1]` 为点击；取第二个元素作为监督标签|
|`205_c`|128 维 SCL 商品向量|通过商品 ID 关联固定内容表；不是上述十个可训练 ID 字段之一|

用户历史来自用户特征表，标签来自曝光记录。历史中的某次交互不等于当前目标曝光的点击标签。内容向量读取与 ID embedding 查表是不同的数据路径。

## 本地索引约定

以下为本项目的内部表示，不是对官方原始字段语义的重新定义。

- ID 索引 0：预留的 padding 行，不分配给已收录的真实非零 ID；历史有效性由 `item != 0` 判断。
- ID 索引 1：词表外 ID（OOV）；不因未知就删除该行为。
- ID 索引 2 及以后：同一字段内已收录的非零原始 ID 一对一映射；不同字段各自独立映射。
- `padding_idx=0` 控制 embedding 第 0 行的梯度处理，不自动补齐历史，也不自动执行注意力屏蔽。
- OOV 行初始化为零，但并非 padding 行；若训练时获得梯度，可以更新。
- 内容表行索引 0 表示缺失内容，与 ID 表的 padding/OOV 标记独立；未知 ID 仍可能有可用内容。

索引规则与字段顺序可核对 [FeatureStore](../src/feature_store.py)，embedding 共享与基线拼接可核对 [C0](../src/c0.py)。本文补充数据解释，不改变训练协议、模型实现或已归档实验结果。
