# 阶段 20：5% MAKE 策略与训练轮数证据

> 文档性质：阶段记录／历史协议。本文中的规模、配置、验证结果及待办状态属于记录时点；当前结果以[主测试](final-test-results.md)、[补充测试](supplementary-test-results.md)和[覆盖说明](current-reproduction-status.md)为准。

## 固定协议

沿用阶段 19：5% 数据、seed 42、历史长度 200、batch size 32、相同公共网络与优化器参数。C5 冻结预训练组复用核心结果，C5-joint 使用同一第三轮多模态表示检查点。所有结果来自完整验证集，未评估保留测试集。

随机冻结明显弱于其他多模态分支训练方案，但 C4 的 LogLoss 低于两个预训练方案。预训练及冻结收益必须按同一评价指标、固定另一因素进行比较，不能将最高 GAUC 与最低 LogLoss 混合成“整体最优”。

## 审计方式

审计检查四组开关、公共参数、代码与数据摘要、完整训练曝光、更新和重载验证；每个训练轮次的保存预测逐条对齐到共同存储，重新计算全部指标。原 C0 与多轮 C0 的第一轮预测另做逐条核对。

```powershell
python scripts/summarize_make_study.py --study <supplement-run> --original-c0 <core-c0> --frozen-pretrained <core-c5> --store <store-050> --output-dir <fresh-audit-directory>
```

配对分析采用 2,000 次按用户 bootstrap、随机种子 2026。区间以固定模型与当前验证人群为条件，不包括训练种子、检查点选择及样本选择的不确定性，不做多重比较校正。

## 解释边界

所有上述审计均已通过，C0 第一轮与原基线在全部 768,773 条验证曝光上的 logit 最大绝对差为 **0**。完整校验和、逐轮核验和配对结果见[策略审计报告](../reports/make-supplement-050-seed42-summary.json)。

|固定因素下的比较|GAUC 绝对增量|95% 百分位区间|
|---|---:|---|
|预训练收益，冻结：C5 − C4-frozen|0.017519|[0.015275, 0.019709]|
|预训练收益，联合：C5-joint − C4|0.001569|[0.000164, 0.003071]|
|继续训练收益，随机：C4 − C4-frozen|0.016391|[0.014739, 0.018059]|
|继续训练收益，预训练：C5-joint − C5|0.000441|[−0.000945, 0.001793]|

本次运行支持预训练在两种固定训练策略下的 GAUC 收益；随机多模态分支需要学习，而预训练后继续联合训练相对冻结的额外 GAUC 收益尚未确认。不能把这个跨零区间解释为两种方式完全等价，也不能宣称冻结必然更好。

这些对照支持“多模态分支的初始化和训练方式值得单独设计”，但不同方案总训练计算量不等。它不是等计算预算比较，也不证明论文工业系统中全部训练机制。此策略网格仅 seed 42；预训练轮数 0/1/3/5 的完整网格、其他种子和最终测试仍未由本批实验覆盖。
