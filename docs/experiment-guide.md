# 实验导读：从研究问题到证据

本页按研究问题组织两个项目。模型编号仅用于定位配置和日志，阅读时以方法名称为主。本文区分方法效果实验与训练方案校准，避免将大量运行误读成不断增加的新方法。

## 一条主线，两个项目

**先研究“内容信息怎样进入推荐模型”，再研究“内容信息怎样帮助寻找并理解更长的用户历史”。**

|项目|研究对象|预期交付|
|---|---|---|
|内容融合（CIKM 2024）|已有固定内容向量如何与 ID 模型结合|融合方式、训练策略及低频商品表现的受控证据|
|长历史兴趣建模（MUSE）|如何选择与目标相关的历史，并利用 ID 与内容共同分析|历史检索、精细聚合、历史长度及分组表现的受控证据|

两个项目使用共同数据划分、内容表示与评估口径，方法上由相似度统计自然衔接。最终结构不同，所以不能直接将两个项目各自最佳分数相减，声称完成单变量升级。

## 第一部分：把内容用起来

|痛点或研究问题|对应方法|关键对照|已获得的证据边界|
|---|---|---|---|
|商品交互稀疏，ID 可能学不充分|ID 基线与内容融合|训练频次分组内比较，保留原始 ID|低频组有提升迹象；不能将所有收益归因于稀疏性|
|有内容向量不等于直接拼接就最好|直接向量融合、逐行为相似度、相似度分桶统计|在公共主干中比较表达方式|三种子完成；排名依指标变化，不要求越复杂越好|
|内容分支与 ID 主干可能需要不同训练安排|内容知识预训练后接入（MAKE）|多轮曲线；随机/预训练 × 冻结/继续训练|预训练有收益，冻结并非必然最佳；额外训练预算不是完全匹配|
|统计信息与预训练知识能否互补|相似度分桶 + MAKE|组合分别对比单独两项|已有三种子 GAUC 证据；不等于所有指标和分组都提高|

MAKE（Multimodal Knowledge Extractor，多模态知识提取器）在此指固定内容向量上的下游 CTR 分支预训练。SCL（Semantic-aware Contrastive Learning，语义感知对比学习）是表示预训练方法；公开数据提供相关固定向量，本项目未重训原始图文编码器。两种“预训练”不可混淆。

## 第二部分：从长历史里找到并利用兴趣

|痛点或研究问题|对应方法|关键对照|已获得的证据边界|
|---|---|---|---|
|仅看最近行为可能错过相关兴趣|内容相似度检索|与最近 K 条历史比较；补类目/ID 检索|前一比较已完成；类目/ID 检索单种子对照与独立审计完成，内容检索领先，待多种子确认|
|找到了相关历史，普通聚合是否足够|相似度分桶统计（SimTier）|固定检索，只增加统计分支|已完成三种子消融|
|ID 注意力缺少内容语义指导|语义感知目标注意力（SA-TA）|固定检索，分别单独加入与组合加入|单独加入有收益；在已有统计分支上额外收益较小且不始终明确|
|更长历史是否真正有用|扩大可搜索历史，但固定选中数量|普通聚合与完整组合都比较 200/1000 条|完整组合三个种子有较一致收益；中间长度、工业十万历史不在已完成证据中|

GSU（General Search Unit，通用搜索单元）负责选择历史，ESU（Exact Search Unit，精细搜索单元）负责分析选中历史。SA-TA（Semantic-Aware Target Attention）通过语义信息调整 ID 注意力分数。SimTier 把目标与历史之间的相似度分桶统计，不保留具体商品身份和顺序。

## 第三部分：确认结果是否可信

多种子检查训练随机性；预测审计核对数据与指标是否算对；按用户配对区间估计固定模型下用户抽样波动；频次和覆盖率分组检查收益是否集中于部分样本。这些是证据检查，不是额外发明的模型模块。

MUSE 原文已有主要 ESU 模块消融，本项目按其结构做本地对照，并补多种子、配对区间与工程核验。MAKE 的四组策略对照进一步区分初始化和是否继续训练。不能笼统宣称原文没有消融。

## 第四部分：最近在做的训练方案校准

最近的 batch 和学习率实验属于这一部分，目的在于找到单卡上可负担、效果可接受的共同训练方案。**它不是从某个新痛点推出一种新的推荐算法。**

|步骤|实际含义|当前状态|
|---|---|---|
|批大小资源扫描|每次处理更多曝光，能否更快、是否有足够内存|32–256 扫描及加长复测完成；512 可行，R4 的 1024 在当前余量策略下未通过|
|学习率筛选|更大 batch 更新次数变少，训练质量是否改变|完整组合的 8 组筛选与逐行审计完成|
|第二种子与伴随模型确认|候选是否只在一个种子或一个模型上表现好|四组训练、逐行审计与配对分析完成；不同模型的速度/效果权衡不同|
|数据规模决定|扩大训练数据能否加强低频/长历史证据，成本是否可接受|本轮选定共同 5% 队列；容量与分组依据见共同规模决策|

同一模型改 batch 和学习率，是训练协议对照；它不能用来证明 SimTier 或 SA-TA 的模块收益。候选调参使用验证集，最高点有选择偏差；保留测试集仍未用于选择。
