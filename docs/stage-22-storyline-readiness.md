# 阶段 22：故事线证据审计与最终测试准入

> 文档性质：阶段记录／历史协议。本文中的规模、配置、验证结果及待办状态属于记录时点；当前结果以[主测试](final-test-results.md)、[补充测试](supplementary-test-results.md)和[覆盖说明](current-reproduction-status.md)为准。

## 审计结论

当前已具备下游核心故事线的验证集证据，但尚未满足最终测试准入条件。两个项目并非两篇论文全部实验的原样复现。审计确认 42 组核心及长度运行报告对应检查点和完整验证预测，验证记录均为 768,773 条，重载误差为零，报告均未评估测试集；清单见[运行库存](../reports/storyline-readiness-inventory.json)。本清单检查检查点存在性，不能替代最终冻结时的权重摘要和验证回放。

## 痛点、改进与证据

|故事环节|现有证据|仍需区分的限制|
|---|---|---|
|ID 与多模态表示的优化需求不同|C0 三轮、C1 三轮曲线；C0 第一轮与原基线逐预测一致|当前优化器与骨架下的现象，不是 ID 只能训练一轮的普遍定律|
|固定多模态表示如何进入推荐模型|C0/C2/C3/C5/C6/C7 三种子与配对审计|向量来自公开数据，不等于重训 SCL；C7 不应因不符合预期被省略|
|MAKE 收益来自哪里|seed 42 的随机/预训练 × 冻结/联合四组对照|策略归因目前单种子；完整预训练轮数网格未完成|
|检索和精细聚合各自起什么作用|R0–R5 三种子消融|R0 是最近 K 两阶段对照，不是独立 DIN 或 SIM-hard/soft|

|收益来自哪些样本|27 组预测的频次、多模态表示覆盖率诊断|描述性 AUC/LogLoss，缺分组置信区间和用户有效历史长度分组|

## 补齐顺序

1. **独立基线与 ID 检索对照**：先固定 B0 DIN、B1 SIM-hard、B2 SIM-soft、G-ID 的结构、历史预算、优化器和梯度路径；核对论文及参考源码后实现。每项先做行为/梯度/资源验证，再 seed 42 全轮，最终主表对照补齐三个种子。不能将 R0 或随机 ID 检索重命名为这些基线。G-ID 中仅用于 no-grad Top-K 的独立随机参数不能冒充训练后的检索器。
2. **必要敏感性与分组**：补 R1/R4 的 L50、L500（先 seed 42，与已完成的 L200/L1000 构成扫描）；补 MAKE P=1/3/5 与 P=0 对照。固定预训练分支冻结策略，避免把轮数与冻结混为一个变量；已有 P=0 四因素对照可复用，P=5 需实际训练，不能从三轮结果外推。补按非 padding 行为数定义的用户历史长度分组。
3. **明确条件与受限项**：TWIN、MISS、G1/G2/G3 仍保留在方法覆盖清单，完成规格和预算判断前不纳入已实现主表。缺少原始图文及替代表示的 SCL 重训、CLIP/OpenCLIP/I2I 对照、工业十万级历史及线上收益保留为受限项。原文分组数附表只有在原分组边界可核实时才称对齐，否则标为本地适配。
4. **冻结后评估测试集**：先完成下述入口与冻结清单，不提前查看测试模型指标。主表优先保留全部既定核心变体，避免仅挑验证集赢家。

额外实验按单张 RTX 5070 12 GB 串行运行。既有 5% 全轮对照每组约 45–65 分钟，可作为初步预算，新增检索或预训练结构须先实测吞吐，不能直接沿用该时长。L50/L500 两模型共四组初估约 3–5 小时，不含实现、审计与其他补充实验；最终测试时间需独立预测吞吐测量后给出。

## 最终测试协议草案（尚未冻结）

- **固定数据**：继续使用现有 5% 共享特征存储和 train-only ID 词表。保留测试集为 923,211 条曝光；不得因分组、缺失多模态表示或末批不足删除记录。分组频次仅来自训练曝光，覆盖率与历史长度按明确掩码计算。
- **固定模型与检查点**：冻结前列出每项模型、种子、配置、权重 SHA256、训练报告摘要、数据清单摘要和实现版本。现有单轮核心用对应最终检查点；C1 的预训练轮数按既定验证 GAUC 选择规则。补充轮数实验必须事先写明选择规则，不按测试结果选择。
- **先验证再测试**：独立只读评估入口先回放验证集，与保存预测及 AUC/GAUC/LogLoss 核对。评估过程不得创建优化器或更新参数，使用 eval/no-grad，记录评估前后权重摘要。直算 SimTier 与缓存须在验证样本上核对；现有缓存只包含训练与验证，不能误用于测试。
- **完整输出**：保存每条测试记录的源行、标签、原始用户分组索引与 logit；逐行核对存储，统一计算 AUC、按有效用户曝光加权 GAUC、LogLoss，同时报告有效用户及曝光覆盖。不同项目指标口径一致，但不同骨架不作为单变量因果对照。
- **统计报告**：三个种子报告均值和样本标准差；预先列出主比较，逐种子做用户配对区间。单种子 bootstrap 不代替训练随机性。重复比较如未校正须明确标注，分组只作预先定义的诊断。测试不作为调参反馈；若发现评估实现错误，保存原产物与修复记录并统一重跑受影响项。
- **发布门槛**：所有主比较的结构、运行和预测审计通过；条件/受限项有明确处置；评估入口验证回放通过；冻结清单完整。未达到这些条件前，测试状态继续为未评估。
