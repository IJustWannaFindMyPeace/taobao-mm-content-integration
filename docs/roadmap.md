# 实施路线

两个项目围绕“痛点、改进、证据、局限”组织实验，阶段产物通过版本控制追踪。下表区分已经完成的工程检查与待完成的研究实验。

|阶段|交付物|验收条件|当前状态|
|---|---|---|---|
|0 · 环境|CUDA 诊断及环境记录|前后向、参数更新、保存重载通过|独立 Conda 环境、CUDA 前后向和保存重载核验通过|
|1 · 数据|来源清单、分片检查、正式子集协议|校验和、字段、ID 对齐、划分与覆盖可追踪|固定版本全量源文件核验完成；1% 与 5% 共享特征存储通过验证|
|2 · ID 基线|C0 训练入口与运行报告|映射与 mask 正确，loss 有限，重载一致|5% C0 三种子核心运行与预测审计完成|
|3 · 评估|AUC、GAUC、LogLoss 与预测文件|不丢记录，完整用户聚合，并列处理正确|完整验证集和按用户配对审计通过；最终测试尚未评估|
|4 · 内容融合|C1、C2、C3、C7|同协议比较，明确表示与融合位置|5% C1 三种子独立预训练与 C2/C3/C7 三种子核心对照完成|
|5 · MAKE|C4、C5、C6 及轮数诊断|结构对齐，预训练与冻结策略可追踪|5% C5/C6 三种子核心对照完成；1% 策略诊断完成，5% seed 42 策略补充对照与预测审计完成|
|6 · 项目衔接|公共接口与来源版本|相同配置的迁移预测一致|公共数据、源码来源和迁移预测核验完成；保留跨项目模型定义差异|
|7 · MUSE|R0–R5 与检索基线|固定公共分支，隔离检索和 ESU 改动|5% R0–R5 三种子完成；R1/R4 长度 200/1000 三种子及审计完成，独立基线仍待补充|
|8 · 综合分析|消融、分组、多种子、资源报告|结论对应证据，记录失败与适配边界|两项目核心三种子汇总完成；5% 频次/覆盖分组与长度稳定性完成；独立基线、敏感性补充及最终测试待完成|
