# MAKE：论文式零轮参考与预训练接入

本报告复用已训练模型，对完整验证集重新核验并补充配对分析，不增加训练，不读取测试集。它是审计后增加的验证分析，不能称为预注册比较。

## 对照定义

[CIKM 图 6(c) 与 §6.3.2](https://arxiv.org/html/2407.19467v1)将零轮定义为 MAKE 随机初始化后随下游联合训练。本地按这一策略设置零轮参考，与预训练 1/3/5 轮后冻结接入的模型比较。数据、架构和轮数网格均为本地适配，不复刻原论文数值。

共同下游条件：5% 用户队列、seed=42、L200、batch=256、两类学习率 0.001、完整单轮训练。MAKE 推荐预训练沿用独立 batch=32 协议。正轮端点改变初始化和冻结状态，比较的是整套接入策略，不是纯粹的预训练轮数效应，总计算量也不相等。

## 验证结果

|预训练轮数与接入方式|GAUC ↑|AUC ↑|LogLoss ↓|
|---|---:|---:|---:|
|0：随机联合|0.586875|0.616942|0.387273|
|1：预训练冻结|0.587955|0.618366|0.387414|
|3：预训练冻结|0.588663|0.618541|0.387329|
|5：预训练冻结|0.588784|0.617410|0.387677|

|相对随机联合零轮|GAUC 差|95% 用户配对区间|
|---|---:|---|
|1：预训练冻结|+0.001081|[-0.000352, 0.002450]|
|3：预训练冻结|+0.001789|[0.000228, 0.003300]|
|5：预训练冻结|+0.001910|[0.000174, 0.003714]|

一轮预训练接入相对随机联合的 GAUC 区间跨零；三轮和五轮的区间为正。三个预训练冻结模型的 LogLoss 均高于随机联合，表明排序指标收益不等于所有指标改善。

三轮、五轮相对零轮有收益，不意味着五轮优于三轮；固定冻结诊断中的三轮减一轮、五轮减三轮区间均跨零。因此本地不支持“轮数越多效果稳定越好”的结论。

## 与额外控制实验的关系

随机冻结零轮继续保留在[固定冻结轮数诊断](shared-pretraining-epochs-v1.md)，用于固定冻结策略检查初始化；随机联合零轮用于本页论文式策略参考。两者不能共用一个未说明的 P0 标签。完整的随机/预训练 × 冻结/联合矩阵见[训练策略诊断](shared-make-strategy-v1.md)。

## 产物核验与限制

四组各 768,773 条验证预测与源行、标签、用户逐行一致，重算指标与训练报告完全相同。数据清单、公共实现及非研究变量配置一致；原有策略和端点审计的报告摘要未改变。报告记录模型、预测和审计文件摘要。

每项区间使用 2000 次用户 bootstrap，未作多重校正，条件于一个已训练种子和同一验证队列，不刻画训练随机性或抽样队列变化。结果不改变既定核心模型选点，也不据此筛选测试集赢家。
