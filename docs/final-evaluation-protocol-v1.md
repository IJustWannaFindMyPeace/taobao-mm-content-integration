# 最终评估候选清单与验证回放门槛

本阶段不训练模型，不创建优化器，不读取保留测试集。先用只读入口回放完整验证集，完成后再生成包含权重摘要的最终冻结清单。当前候选清单已确定，不表示测试评估已经开始。

## 预定义解释关系

- 内容融合保留各方案对 ID、统计＋MAKE 分别对统计和 MAKE，以及逐行为相似度对组合的比较。
- MUSE L200 保留内容检索对近期历史、统计/语义各自对普通聚合、完整组合对各单模块与统计分支的比较。
- 普通聚合及完整组合各自比较 L1000 与 L200；L1000 固定增强聚合比较内容与类目、两种 ID 检索及等权融合。
- 逐种子报告 AUC、GAUC、LogLoss、用户配对区间，并报告三种子均值与波动。全部比较保留，无提升或负向结果不删除；区间未作多重校正须注明，不能当确认性显著性清单。

## 只读回放

`evaluate_checkpoint.py` 从训练报告重建结构，加载完整权重，关闭梯度，使用原 batch 顺序和完整末批。每组完整 768,773 条验证预测须与原预测逐元素一致，源行、标签、用户及重算指标一致。SimTier 在线分桶还须逐批与已核验缓存完全相同。入口目前只支持验证集，不能意外触发测试。

`run_validation_replay.py` 串行执行固定清单，核验训练报告和评估源码摘要；任何差异立即停止，不自动放宽容差、不改模型、不缩小 batch。完成后记录所有权重摘要，再扩展经验证的入口供测试使用。

## 测试准入

54 组回放通过后，冻结数据清单、训练报告、配置、权重、运行环境、模型源码、评估源码与比较列表。完整保留测试集共 923,211 条曝光，统一评估完整用户；测试指标不能反馈用于调整学习率、轮数、融合权重或替换主表模型。重复读取只允许有记录的失败恢复或评估错误修复，不能据结果开展新的模型选择。
