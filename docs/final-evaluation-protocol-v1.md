## 预定义解释关系

- 多模态融合保留各方案对 ID、统计＋MAKE 分别对统计和 MAKE，以及逐行为相似度对组合的比较。
- MUSE L200 保留多模态检索对近期历史、统计/语义各自对普通聚合、完整组合对各单模块与统计分支的比较。
- 普通聚合及完整组合各自比较 L1000 与 L200；L1000 固定增强聚合比较多模态表示与类目、两种 ID 检索及等权融合。
- 逐种子报告 AUC、GAUC、LogLoss、用户配对区间，并报告三种子均值与波动。全部比较保留，无提升或负向结果不删除；区间未作多重校正须注明，不能当确认性显著性清单。

## 只读回放

`evaluate_checkpoint.py` 从训练报告重建结构，加载完整权重，关闭梯度，使用原 batch 顺序和完整末批。每组完整 768,773 条验证预测须与原预测逐元素一致，源行、标签、用户及重算指标一致。SimTier 在线分桶还须逐批与已核验缓存完全相同。入口默认回放验证集；显式测试模式必须提供冻结清单和模型 ID，并核对权重、配置、代码与数据摘要。

`run_validation_replay.py` 串行执行固定清单，核验训练报告和评估源码摘要；任何差异立即停止，不自动放宽容差、不改模型、不缩小 batch。全部回放已完成并记录权重摘要。扩展入口再次完成统计＋MAKE、完整 MUSE 和等权融合检索的完整验证回归，三组逐预测误差均为零。
