## 附录与工程记录的分工

附录保留公共超参数、三种子逐模型数值、所有区间、分桶敏感性、适配结构差异、数据版本与审计说明。batch/学习率试选过程不进入核心故事，但最终设置必须公开。下载、环境故障、重启与权限问题留在工程历史，不占研究正文。

预训练轮次、历史长度和初始化/冻结策略直接检验研究问题，应留在正文。负结果与显著性不足的比较也不能借“篇幅”删去。原始三种子数据已公开，可在正式排版时按结论聚焦，而不是只展示表现最好的种子。

## 从头学习的顺序

1. 任务与数据：目标广告、历史、标签和内容向量各是什么。
2. 内容如何进入模型：从ID基线到四种内容表达方式。
3. 训练为何需要拆开：MAKE的四格控制与轮数分析。
4. 历史为何需要搜索：GSU筛选、ESU聚合及其消融。
5. 结果为何不完全符合论文：指标、适配、负结果与行为诊断。
6. 如何公开表达结论：用图表构建主张，保留证据边界。

学习讲解不把检查问题写入公开研究文档；练习与答疑留在对话中。PPT定稿后还需检查页面可读性、数字转录和演讲时长，无需因此重训模型。

## 图表再生成

图表由内容集成仓库脚本统一生成，并同步到MUSE仓库。绘图依赖与训练环境分开；从同时包含两个项目的工作目录运行：

```powershell
python -m venv work/storyline-plot-env
work/storyline-plot-env/Scripts/python.exe -m pip install -r projects/taobao-mm-content-integration/requirements-storyline.txt
work/storyline-plot-env/Scripts/python.exe projects/taobao-mm-content-integration/scripts/render_storyline_figures.py
```

Windows默认使用微软雅黑；其他系统可用 `--font /path/to/cjk-font.ttf` 指定中文字体。渲染只读取公开的 `storyline-evidence.json`，不需要训练数据或模型。若要从原始报告重新导出素材包，使用 `build_storyline_evidence.py --work work`，需要保留的本地内容预训练报告；来源摘要记录在素材包中。

核验入口为 `audit_storyline_evidence.py --work work`。该脚本回查原报告及图像指纹，不训练模型；完整来源核验需要本地预训练报告，公开图表本身可直接使用。
