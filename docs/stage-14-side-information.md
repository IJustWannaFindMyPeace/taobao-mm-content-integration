# Vector 与 SimScore 融合对照

> 历史阶段记录：本页实验采用早期 1% 用户与 batch 32。Vector 的正式结构、5% 三种子测试结果及结论边界见 [Vector 内容融合](vector-integration.md)；本页待办措辞反映当时状态。

## 来源与研究问题

[CIKM 2024 §4、§6.1.3](https://arxiv.org/html/2407.19467v1#S6.SS1.SSS3) 将 Vector 定义为逐商品内容与 ID 的融合，将 SimScore 定义为逐历史行为的语义相似度侧信息。论文没有给出可直接复用的完整生产网络。

本阶段补齐 C2、C7，检查在当前公共主干上直接使用内容向量或逐行为相似度的表现。不能预设它们必然弱于 SimTier 或 MAKE。

## 具体适配

两组继承 C0 的用户/商品词表、两个注意力分支、MLP、优化器和初始化。固定 SCL 内容经 L2 归一化，历史聚合之前进行侧信息融合。

|配置|侧信息|融合位置|
|---|---|---|
|C2 Vector-adapted|目标和各历史商品的 128 维内容|目标与逐历史 ID/类目表示|
|C7 SimScore-adapted|逐历史余弦相似度及有效标记，共 2 维|逐历史 ID/类目表示|

投影写作 `x_fused = x_ID + W(side)`，等价于拼接 `[x_ID, side]` 后应用 `[I, W]`。输出保持 32 维，ID 块固定为恒等映射；这是为对齐公共网络而采用的受约束投影，并非任意宽度的拼接网络。Vector 共享目标和历史的侧信息投影。融合表示进入 C0 的匹配网络并作为聚合值，因此侧信息可影响注意力分数及兴趣向量，不是只在池化后拼接。

侧信息投影零初始化，确保初始预测与 C0 完全一致。梯度检查确认投影可更新，固定内容输入不会获得梯度。缺失内容置零而保留 ID 行为；SimScore 同时输入相似度有效标记，区分缺失与有效的零相似度。缺失标记本身也可能提供信息，不能把所有收益都归因为语义相似度。

## 协议与运行

使用相同 1% 用户子集、seed 42、最近 200 条历史、短分支 50 条、batch 32，完整训练一轮并评估全部验证记录。测试集不参与。运行入口：

```powershell
python scripts/run_side_study.py --store <feature-store> --output-dir <fresh-study-directory>
```

队列先执行 C2，再执行 C7；每项写入独立日志、报告、预测及检查点。失败时停止后续任务。资源开销独立记录，训练不并行运行。

## 当前状态与解释边界

实现及 30 项单元测试通过，两项完整训练均已完成，结果见下文。测试包含初始预测一致、缺失内容替换不变性、空历史有限输出、侧信息梯度及固定内容无梯度。

完成后分别相对 C0、C3 做配对验证比较。这些结果属于本项目明确定义的适配，不代表原论文私有生产架构的原样复现。模型容量、侧信息投影瓶颈、训练轮数和缺失标记均会影响结果，最终结论仍需多种子及保留测试集。

## 完整验证结果：1% 子集，seed 42

|方案|AUC|GAUC|LogLoss|
|---|---:|---:|---:|
|C0 ID|0.591355|0.556495|0.393647|
|C2 Vector|0.593907|0.562326|0.397097|
|C7 SimScore|0.603609|0.579611|0.393239|
|C3 SimTier|0.607081|0.573526|0.392944|
|C5 MAKE|0.606048|0.574518|0.392163|
|C6 SimTier + MAKE|0.610798|0.578650|0.391416|

两组均训练 609,902 条记录、验证 151,947 条记录，保存重载误差为零。Vector 训练 456.4 秒，SimScore 训练 460.2 秒；分配显存峰值分别为 2,837.39 和 2,836.76 MiB，不含驱动及 CPU 特征存储。

Vector 相对 C0 的 AUC/GAUC 提升，但 LogLoss 变差。SimScore 的 GAUC 点估计高于 SimTier 与组合模型，而 AUC/LogLoss 弱于二者。这说明本轮不能给出所有指标一致的方法排名，也没有完整复现原论文的排序。

GAUC 按用户内部的正负排序计算，AUC 考察整体排序，LogLoss 评价概率预测损失，三者可能出现不同方向。这里只观察到指标差异，尚未通过误差分组确定其成因。投影瓶颈、侧信息有效标记、数据规模、训练轮数和随机种子都属于待验证因素，不直接认定任何一项为原因。
