# MAKE：推荐预训练（点击率预测任务）与接入

## 研究问题与方法

MAKE（Multimodal Knowledge Extractor）通过提前训练多模态兴趣网络，缓解多模态相关参数与 ID 模型的训练需求差异。[CIKM 2024 §4.3](https://arxiv.org/html/2407.19467v1#S4.SS3)以多模态 CTR 任务预训练 DIN 兴趣模块及 MLP，再将兴趣和中间特征接入下游。本项目使用固定 SCL 输入，不重训商品编码器；聚合网络层宽、ReLU 和下游接入为公开数据适配。

归一化后的目标与历史多模态向量各为128维，逐行为拼接 `[q, h, q-h, q*h]`，经 `512 → 80 → 40 → 1` 网络生成聚合分数。分数不做 softmax，直接加权历史多模态向量并求和，得到128维兴趣向量。预测头为 `128 → 128 → 64 → 32 → 1`，隐藏层使用ReLU，以二元交叉熵训练。

接入时拼接128维兴趣向量与32维隐藏特征，得到160维 MAKE 特征；预训练输出层不参与迁移。该特征经无偏置 `160 → 128` 投影，与 ID 主干第一层输出相加，再经过激活和后续预测层，等价于拼接输入后的对应线性变换。新增投影零初始化，即使冻结 MAKE 分支，接入层仍然训练。实现见 [make.py](../src/make.py) 与 [make_fusion.py](../src/make_fusion.py)。

## 实验协议

使用固定5%用户队列、历史窗口200、三个种子42/2026/3407。下游batch 256、训练一轮；MAKE 推荐预训练沿用独立阶段的batch 32、AdamW、学习率0.001、weight decay 0。主表预训练权重按各种子前三轮的验证GAUC选择；固定轮数实验则使用同一轨迹的第1、3、5轮，不以测试效果选点。数据及下游设置见[公共协议](../configs/shared-downstream-protocol-v1.json)和[数据划分](sampling-and-splits.md)。

主表 MAKE（C5）与组合（C6）均冻结预训练多模态分支。组合将20维SimTier统计通过另一投影加入同一预测层，三路并行汇合，不将统计输入MAKE。初始化与更新策略的四组对照是本项目补充设计：随机冻结、随机联合、预训练冻结、预训练联合。四组共享下游设置，预训练成本另计。

## 主测试：特征接入与组合

下表为三种子测试均值。

|方法|AUC ↑|GAUC ↑|LogLoss ↓|
|---|---:|---:|---:|
|ID基线|0.605518|0.573708|0.391709|
|SimTier|0.616165|0.590215|0.390417|
|MAKE冻结接入|0.619105|0.590055|0.390042|
|SimTier＋MAKE|0.619468|0.591200|0.390150|

MAKE及组合相对ID的GAUC配对区间在三个种子均为正，支持预训练多模态特征的价值。组合相对SimTier平均ΔGAUC为+0.000985，区间方向为跨零／正／跨零；相对MAKE为+0.001144，方向为正／正／跨零。组合平均排序指标更高，但额外收益有限，LogLoss也未全面优于单模块。两类特征使用相同多模态表示与历史，信息重叠是合理解释。

## 追加测试：训练策略与轮数

|研究问题|对照|结果|
|---|---|---|
|预训练是否有效|预训练联合 − 随机联合|ΔGAUC为+0.004279、+0.005000、+0.002841，三区间均正|
|接入后是否继续更新|预训练联合 − 预训练冻结|ΔGAUC为+0.002496、+0.001717、+0.001808，三区间均正|
|预训练是否越久越好|冻结接入P3 − P1；P5 − P3|前者三区间跨零；后者一个跨零、两个负向|

种子顺序为42、2026、3407。结果支持先预训练再联合适配，而不支持持续增加预训练轮数。论文式零轮是随机联合；早期额外的随机冻结零轮另行保留。P0联合与正轮冻结改变两项因素，预训练作用由四组策略对照判断，轮数趋势主要由同为冻结的P1/P3/P5判断。

该阶段发生在主测试结果已查看之后，单独归档；主表仍保留原冻结方案，不以追加结果替换主表。统计区间采用2000次用户配对bootstrap，条件于固定模型与队列，未作多重校正。

## 结论与证据

MAKE有效地将预训练多模态兴趣迁移到ID推荐模型；本地策略实验进一步支持接入后的联合更新。预训练更久和叠加统计模块并不保证持续增益。这与论文的预训练动机一致，但不同于其轮数持续改善及组合全面领先的结果。
