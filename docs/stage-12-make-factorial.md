# MAKE 接入与训练轮数对照

> 历史阶段记录：当前方法、三种子测试及方案定义见 [MAKE预训练与组合](make-integration.md)。本页早期设置、验证结果与当时待办不替代正式结论；零轮须区分随机冻结与随机联合。

## 研究问题

阶段 11 的内容分支在第二轮验证最优，第三轮回落。该现象尚不能证明 ID 与内容具有不同的最优训练轮数，也不能证明预训练接入有益。本阶段补充 C0 三轮诊断和 MAKE 的双因素对照。

方法依据 [CIKM 2024 §4.3](https://arxiv.org/html/2407.19467v1#S4.SS3)：利用 CTR 预训练内容兴趣模块，再将兴趣向量及 MLP 中间表示接入推荐模型。本项目的层宽、中间层选择、融合初始化与冻结策略均属于公开数据适配。

## 控制变量

|配置|内容初始化|接入后内容参数|作用|
|---|---|---|---|
|C4|随机|联合训练|从头学习内容使用方式|
|C4-frozen|随机|冻结|随机固定表示控制组|
|C5|C1 第二轮|冻结|迁移固定的已学习表示|
|C5-joint|C1 第二轮|联合训练|迁移后继续优化|

比较 C5 与 C4-frozen，或 C5-joint 与 C4，分别在固定训练策略下检查预训练作用。比较 C4 与 C4-frozen，或 C5-joint 与 C5，检查冻结策略。单独比较 C4 与 C5 同时改变两个因素，不能归因于预训练。

预训练第二轮检查点来自阶段 11 的验证 GAUC 选择；测试集不参与。四组后续均训练一轮，因此预训练组总计算预算更大，不能据此宣称等计算量下更优。

## 融合结构与实现

公共 ID 主干保持 C0 的结构、初始化、词表、优化器和样本次序。MAKE 提供 128 维兴趣向量与 32 维隐藏层，将二者拼接后经无偏置线性投影加入公共 MLP 第一层的激活前输出。这等价于向第一层输入追加内容特征。

新增投影初始化为零，使各组初始预测等于 C0。其第一步会阻断内容分支梯度；投影更新后，联合训练分支能获得梯度。预训练 logit 输出层不用于融合，也不参与下游更新。

加载预训练权重时验证检查点 SHA256、特征存储版本及历史长度。冻结参数排除在优化器之外；固定 SCL 向量始终不更新。

28 项单元测试通过，包括公共参数逐项相等、初始预测一致、融合投影梯度、冻结与联合训练梯度路径，以及既有缺失值和指标契约。

## 执行与产物

```powershell
python scripts/run_make_study.py --store <feature-store> --pretraining-run <c1-run> --output-dir <fresh-study-directory>
```

队列先执行 C4/C5 的 20 步工程检查，再执行 C0 三轮与四组 MAKE 一轮训练。所有训练串行使用同一张 GPU；任一任务失败即停止后续任务。完整配置位于 `configs/`。

每个任务记录完整验证指标、逐轮训练时间与显存峰值、输入及代码 SHA256、预测和最终模型。`status.json` 记录队列状态，各任务具有独立日志和目录。模型文件只包含模型参数，不支持精确恢复优化器进度；中断后的任务需要新目录重新运行。

C0 三轮从初始化重新训练，保持优化器跨轮连续；第一轮预测将与已有 C0 结果核对。逐轮验证仅做前向计算，不改变训练样本顺序或参数。

当前状态：实现与单元测试完成，两组资源检查通过，正式实验队列已全部完成。完整结果见下文。20 步检查不用于方法收益结论。

## 解释边界

该轮实验仍使用 1% 固定用户子集和单种子。需要后续随机种子、低频分组及规模检查验证稳定性。C0 与 C1 的结构不同，轮数曲线只能反映本项目具体实现；完整 MUSE 的可用数据规模还需测量检索和 ESU 模块。

整套队列完成后运行：

```powershell
python scripts/summarize_make_study.py --study <study-directory> --original-c0 <original-c0-run> --output-dir <fresh-comparison-directory>
```

入口拒绝未完成或失败的队列，核验数据版本、公共配置、训练行数及保存重载，再输出四组因素对照与各组相对 C0 的配对比较。已实际验证未完成队列会被拒绝，且不生成结果目录。GAUC 用户 bootstrap 区间仅反映固定已训练模型和当前子集上的不确定性；多个探索性比较未做多重检验校正，不用于宣称已获得稳定显著收益。

所有轮次均处理 609,902 条训练记录，完整验证 151,947 条；保存重载预测误差均为零。C0 三轮与四组融合训练合计约 51.6 分钟，不含验证、保存与先前内容预训练。融合训练峰值分配显存约 2.79 GiB，未发生 OOM。这不能直接外推到更大词表、历史长度或完整 MUSE。

C0 在线训练 LogLoss 从 0.38550 降至 0.26264、0.16425，但验证 LogLoss 显著升高；验证 GAUC 也逐轮下降。与内容分支第二轮较优的曲线共同观察，本实现呈现训练轮数需求不同的现象。该诊断受到用户不重叠验证、ID 稀疏性、结构和优化器选择影响，不代表工业系统必然如此。

C5 在本轮四组融合模型中三个验证指标均最佳。需要结合固定策略下的配对比较判断预训练作用；不应仅用 C5 与 C4 的差异归因于预训练。

固定冻结策略时，预训练组优于随机冻结组；联合训练时，预训练的增量区间跨零。预训练后继续联合训练的点估计低于冻结，但对应区间也跨零，尚不足以确认冻结策略稳定更好。上述区间未作多重比较校正，也不包含随机种子或子集选择的不确定性。
