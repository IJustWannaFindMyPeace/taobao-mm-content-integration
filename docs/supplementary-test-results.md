# 统一追加测试：结果与故事线

更新日期：2026-09-25。73 份补充下游模型均完成同一 923,211 条曝光的测试评估，93 项预先固定比较全部完成。测试前，73 份完整验证预测逐元素重放一致。该阶段补齐正式补充模型的测试证据；原主实验 54 份模型、66 项比较不变。

本阶段是在已查看主测试结果后开展的追加评估，不是一次新的盲测。没有根据追加测试选择检查点、修改参数或重训。所有结论限定于同一 5% 用户队列和三个训练种子，不代表全量数据或工业线上收益。

## 痛点、改进与证据

下表的“正向”“负向”指单项 GAUC 差值的 95% 用户 bootstrap 区间完全位于零的一侧；“跨零”表示当前证据不足以明确方向。每项使用 2000 次重采样，未作多重比较校正。三个种子使用相同数据，不能视作三个独立数据集。

|研究问题|对照与改进|追加测试证据|解释与局限|
|---|---|---|---|
|内容分支是否需要先学习？|MAKE 随机联合 → 预训练后联合|三个种子均正向；ΔGAUC 为 +0.004279、+0.005000、+0.002841|支持本设置下的预训练收益；有额外训练成本|
|接入后是否继续更新内容分支？|预训练冻结 → 预训练联合|三个种子均正向；ΔGAUC 为 +0.002496、+0.001717、+0.001808|不支持“冻结一定更好”；排序与概率损失须分别查看|
|ID 多轮是否有风险？|ID 第1轮 → 第3轮最终模型|三个种子均负向，约 −0.035 至 −0.038|支持本设置下多轮泛化退化；第2轮权重未保存，只保留验证诊断|
|预训练是否越久越好？|固定冻结的 P1 → P3 → P5|P3−P1 三个区间均跨零；P5−P3 一个跨零、两个负向|收益不单调，不能按测试结果选择最佳轮数；P0联合与正轮冻结也不是纯轮数对照|
|SimTier 分桶边界是否影响结果？|既有 floor → 字面 ceil / 保留计数的右闭解释|字面实现：单独统计三种子均负向，组合两个负向、一个跨零；右闭解释无一致优势|字面边界会丢计数；不能选分数最高的版本冒充唯一原版|
|短历史的注意力形式是否关键？|点积 softmax → DIN 局部激活适配|三个种子均跨零|当前证据不能确定优劣，也不是证明两种模型等效|
|筛选与聚合使用一致评分是否足够？|TWIN 内容检索对照 → 一致 ID 评分适配|三个种子均负向|多头检索的候选并集预算不同，不能归因为单一模块，更不否定原工业 TWIN|
|双路检索是否稳定互补？|MISS 内容双路 → 协同/内容双路适配|一个种子负向、两个跨零；共享参数对照三个均跨零|没有稳定 GAUC 增益；原论文系统未被完整重建|
|学习式内容检索是否胜过固定余弦？|原内容余弦 → G1 两阶段投影检索|三个种子均负向；ΔGAUC 为 −0.003114、−0.003525、−0.003716|增加监督与复杂度并未自动改善检索|
|共享融合评分是否更有效？|原内容余弦 → G3 共享融合评分|一个跨零、两个负向；种子2026下降约0.0216|保留负结果与种子差异，不能扩展为所有学习检索都无效|
|更多历史能带来多少增益？|完整 MUSE：L50 → 200 → 500 → 1000，K固定50|前两段均三种子正向；500→1000 两个跨零、一个正向|收益并未稳定随长度增长；不能据测试挑选500或1000作为新最优配置|

种子数值顺序为 42、2026、3407。上述条目为问题导向摘要，不替代全部 AUC、GAUC、LogLoss 与区间。完整模型配置、基线/候选身份均可从下方报告追溯。

## 验证与测试有哪些变化？

既有 84 项验证比较均按原模型身份映射到测试。9 项 GAUC 区间方向分类发生变化，75 项不变；这只是描述性计数，不是复现成功率。

- MAKE P1 对 P0联合：种子42、3407从跨零变为正向，因此测试为三个种子正向。
- MAKE P5 对 P0联合：种子42从正向变为跨零，3407从负向变为跨零，因此测试为三个种子跨零。
- MISS 参数共享比较：种子2026从正向变为跨零，测试三个种子均跨零。
- 普通内容检索注意力：种子2026的50→200、200→500，以及3407的500→1000，从跨零变为正向。
- 完整 MUSE：种子3407的500→1000从跨零变为正向；另外两个仍跨零。

原验证报告作为历史证据保留，不把其数值或文字悄然改写为测试结果。区间分类改变不等于两个评估划分之间存在统计显著差异。

## 两项目如何衔接？

内容集成项目检验“已有固定内容表示，如何让推荐模型用好它”：直接向量、逐行为相似度、分桶统计、MAKE 预训练与训练策略。MUSE 项目继续检验“历史更长时，先看哪些行为，再如何聚合”：GSU（General Search Unit，通用搜索单元）筛选，ESU（Exact Search Unit，精细搜索单元）聚合，并拆分统计与语义注意力贡献。

这是一条研究问题的递进路径，不是把 MAKE、TWIN、MISS、G1、G3 依次叠加成一个必然更优的模型。两项目共享队列、标签、内容表、主干公共设置与评估口径；预训练次数、历史预算、结构和参数量是明确列出的研究差异，不宣称等总计算量。
