# 两论文复现：当前覆盖与故事线

更新日期：2026-09-24。本文是当前状态入口；[2026-09-23 审计](paper-coverage-audit-2026-09-23.md)保留发现时点的缺口，不能用其中的旧状态判断当前完成度。

## 当前结论

两个项目的衔接仍成立：先研究固定多模态表示如何进入 CTR 模型，再研究其如何筛选和聚合长历史。已完成既定主实验及一批审计后补充实验，但不等于原论文所有实验、模型细节和工业系统已复现。

所有主实验共享既定 5% 用户队列、公共下游协议和三个种子。补充实验保留同一数据与公共设置，但不同结构的历史预算、参数量、预训练成本仍不同；不能称所有方法等总计算预算。

## 当前输入与系统限制

- 未重训 SCL 图文编码器，缺原搜索/购买配对；CLIP-O/E、OpenCLIP、I2I 的原表示对照不完整。固定内容向量不能替代这些实验。
- 选中原始历史列表最多 1000 条，测试用户约 96.75% 达到此上限。9 个用户组中第 2–9 组均长 1000，不能据此声称恢复真实长历史长度趋势。
- 工业部署、线上收益、原图像语义案例及私有模型细节不能由当前匿名数据等价恢复。
- 5% 是当前采用的研究规模，不是 RTX 5070 12GB 最大可训练规模的实测结论。

## 完成口径

主实验冻结测试已完成；审计后的 MAKE 轮数及 SimTier 分桶批次也已完成。仍应表述为“公共协议下的下游适配复现与机制验证”，而不是“除不可复现项外全部完成”。负结果、跨零区间和方法差异都属于故事线的一部分。
