# MAKE 预训练轮数诊断：固定 P=0/1/3/5

> 历史阶段记录：当前方法、三种子测试及方案定义见 [MAKE预训练与组合](make-integration.md)。本页早期设置、验证结果与当时待办不替代正式结论；零轮须区分随机冻结与随机联合。

本实验检查内容知识预训练轮数如何影响冻结接入后的 CTR 模型。seed=42，四个固定端点不按结果更改，内容分支的冻结策略和下游模型保持相同。

## 与论文零轮对照的区别

CIKM 图 6(c) 的零轮 MAKE 未预训练，但参与下游联合训练。本页零轮是随机冻结，用于固定冻结策略隔离初始化，属于额外控制实验，不是原图的直接复刻。论文式随机联合参考见[训练策略诊断](shared-make-strategy-v1.md)，其验证 GAUC 为 0.586875；不得与本页随机冻结的 0.572962 混称。

## 训练安排

内容预训练沿用原独立设置：L200、batch=32、AdamW 学习率 0.001、weight decay=0，固定内容向量不更新 SCL 编码器。从同一随机种子开始完整训练五轮，逐轮保存权重和完整验证预测。旧检查点没有优化器状态，不采用只加载权重后继续两轮的伪续训。

本次唯一预训练配置变化为 epochs 3→5，启动前核对训练入口与 ContentMAKE 源码摘要未变。完成后将前三轮与已有三轮运行逐预测、逐权重核验；不能提前假定其一致。若不一致，不混用不同轨迹的 P1/P3/P5，需明确差异并采用同一轨迹对照。

|固定端点|下游设置|
|---|---|
|P0|随机内容分支冻结；引用共同策略诊断的随机冻结组|
|P1|第 1 轮内容权重冻结接入|
|P3|第 3 轮内容权重冻结接入；仅在轨迹与配置一致时复用现有结果|
|P5|第 5 轮内容权重冻结接入|

下游各组均 batch=256、两类学习率 0.001、单轮、L200，数据与种子相同。预定义相邻比较 P1−P0、P3−P1、P5−P3，同时记录预训练成本；这不是等总计算量对照。预训练自身 CTR 曲线不能代替冻结接入后下游效果。

## 解释与状态

五轮预训练与轨迹核验已完成，P1/P5 下游对照与四端点预测审计均已完成。该单种子诊断不修改核心主表已确定的验证选点，更不会用测试结果选择 P。若后续收益饱和或变差，保留结果，不继续添加轮数以寻找更高点。保留测试集未评估。


## 轨迹审计结果

原三轮与新五轮所有保存轮次均核对完整验证源行、标签、用户和重算指标，训练记录均包含 3,052,475 条曝光，检查训练步数及每轮权重 SHA-256。前三轮逐预测最大绝对误差均为 0，所有权重张量逐元素完全一致，支持复用相同配置的原 P3 下游结果。

五轮内容分支自身的验证 GAUC 依次为 0.580717、0.582168、0.582525、0.581748、0.583192。它并非逐轮单调增加，也不能据第五轮的分支指标推断冻结接入后的 CTR 效果。

新增入口 `audit_pretraining_prefix.py` 执行完整轨迹核验，`run_pretraining_endpoints.py` 在核验通过后串行训练 P1/P5。P0 来自共同策略的随机冻结组，P3 来自共同核心预训练冻结组，四点结果已完成独立预测和受控配置审计。每项只改变预训练权重来源，其余下游配置保持一致。

[轨迹审计报告](../reports/content-pretraining-p5-prefix-audit.json)保留逐轮预测/权重摘要及完整指标。当前未评估保留测试集。


## 冻结接入后的下游结果

|预训练轮数|GAUC ↑|AUC ↑|LogLoss ↓|
|---|---:|---:|---:|
|0|0.572962|0.605987|0.388752|
|1|0.587955|0.618366|0.387414|
|3|0.588663|0.618541|0.387329|
|5|0.588784|0.617410|0.387677|

|固定相邻比较|GAUC 差|95% 用户配对区间|
|---|---:|---|
|p1-vs-p0|+0.014993|[0.012895, 0.017165]|
|p3-vs-p1|+0.000708|[-0.000643, 0.002011]|
|p5-vs-p3|+0.000121|[-0.001131, 0.001495]|

P1 相对随机冻结有正向区间；P3−P1、P5−P3 均跨零，不能认定继续增加轮数带来稳定 GAUC 提升或统计等效。P5 的 GAUC 点估计略高，但 AUC、LogLoss 比 P3 更差。该结果支持预训练有用，不支持“越多轮越好”，也不以本单种子曲线改写主表原有选点。

四组完整预测核对源行、标签、用户和重算指标；下游除是否预训练/权重来源外配置一致，公共实现一致，预训练端点权重摘要与同一五轮轨迹对应。P3 前缀已验证精确一致。各组完整训练同样一轮曝光；P0/P1/P3/P5 的总预训练成本不同，不能排除预算因素。

三个区间各用 2000 次用户 bootstrap，未作多重校正；仅一个种子、同一验证队列，不是独立测试证据。[完整下游审计](../reports/shared-pretraining-endpoints-v1-seed42-audit.json)。
