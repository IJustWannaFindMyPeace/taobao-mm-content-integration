# 测试集商品频次分组：主实验后的补充分析

本分析在主实验测试结果公开后开展，属于事后分析，不加入原有 66 项冻结比较。复用全部 54 组已冻结模型的测试预测，没有重新训练或重新预测。预测摘要全部与主实验记录一致；训练与测试曝光来源经过校验，源行、标签、用户逐行对齐。

频次仅由训练集目标商品曝光次数计算，沿用既有 0、1、2–5、6–20、21–100、101+ 六组，未按测试表现调整边界。频次为零不代表新商品或历史中从未出现。每组报告 AUC 和 LogLoss；这里没有分组置信区间，不宣称统计显著或因果关系。

两项比较的低频组平均 AUC 增量均更大，与验证阶段的描述性趋势一致。这增加了低频机制解释的测试分组证据，但不是原先未看测试结果时预先冻结的验证，也没有排除类别分布、内容覆盖及其他相关因素。

完整结果保留全部 54 模型、六组的 AUC、LogLoss、曝光数、目标商品数与点击数，而不是仅保存上述两项正向比较。高频组的本次统计＋MAKE 平均增量也为正，与验证分组的近零均值不同；不应把某个群体的验证点估计视为不变规律。
