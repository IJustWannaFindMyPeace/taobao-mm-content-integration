# SimTier 与 MAKE 的互补性对照

> 历史阶段记录：当前方法、三种子测试及方案定义见 [MAKE预训练与组合](make-integration.md)。本页早期设置、验证结果与当时待办不替代正式结论；零轮须区分随机冻结与随机联合。

## 研究问题与控制变量

C3 将目标与历史的语义相似度转成分桶计数；C5 将预训练多模态兴趣向量及隐藏层接入 ID 模型。C6 同时使用两种特征，检验统计信息是否能补充已学习的多模态兴趣。

C6 使用与 C5 相同的 C1 第二轮检查点并冻结多模态分支，使用与 C3 相同的 20 桶计数缓存。数据仍为 1% 用户子集，seed 42、历史长度 200、batch 32，下游训练一轮。预训练轮数来自验证集选择，不使用测试集。

## 实现

公共 ID 表示、MAKE 兴趣及隐藏层投影、SimTier 计数投影在公共 MLP 第一层的激活之前相加，等价于向第一层追加两组特征。两个新增投影均为零初始化；C6 的公共参数和 MAKE 初始参数与 C5 一致。测试验证初始预测一致、两个融合投影可获得梯度，以及冻结多模态分支不更新。

新增 `C6` 类位于 `src/make_fusion.py`，配置位于 `configs/c6.json`。统一训练入口分别校验多模态表示检查点与分桶缓存的来源、校验和和历史长度。

```powershell
python scripts/train_c0.py --store <feature-store> --config configs/c6.json --content-checkpoint <c1-run>/epoch-2.pt --hist-cache <simtier-cache> --output-dir <fresh-c6-run>
```

## 比较与解释

- C6 对 C5：固定预训练多模态分支及公共主干，检查增加分桶统计的作用。
- C6 对 C3：固定分桶统计及公共主干，检查增加预训练多模态分支的作用；后者使用额外预训练计算量。
- 若只优于其中一个单独方案，不能直接称为互补性成立。

比较使用相同行标识的完整验证预测和用户配对 bootstrap。即使组合的点估计较高，也需结合区间、额外计算量和多种子结果解释。当前配置来自前序验证实验，后续仍须使用保留测试集评估最终方案。

## 当前状态

实现和 29 项单元测试已通过，单种子完整训练与配对比较已完成。此次实验不会确定完整 MUSE 的最大数据规模。

## 单种子验证结果

|方案|AUC|GAUC|LogLoss|
|---|---:|---:|---:|
|C3：SimTier|0.607081|0.573526|0.392944|
|C5：MAKE|0.606048|0.574518|0.392163|
|C6：组合|0.610798|0.578650|0.391416|

|配对比较|GAUC 差值|95% 用户 bootstrap 区间|
|---|---:|---|
|c6-vs-c3|+0.005124|[+0.000660, +0.009370]|
|c6-vs-c5|+0.004132|[+0.002010, +0.006237]|

C6 在本次验证中优于两个单独方案，两个 GAUC 增量区间均高于零，为当前实现的互补性提供初步证据。区间仅条件于当前已训练模型和固定子集，未包含训练种子差异或数据子集选择，也未进行多重比较校正；不能据此宣称已完成稳定的论文复现。

本轮完整训练 609,902 条记录，验证 151,947 条记录。训练耗时 476.2 秒（约 7.94 分钟，不含验证、保存和MAKE 推荐预训练），PyTorch 峰值分配显存 2,852.10 MiB；参数更新检查通过，重载最大预测误差为零。测试集未参与。

来源核验确认 C6 与 C3 使用同一分桶缓存，与 C5 使用同一预训练检查点，三组公共训练配置与特征存储版本一致。机器报告：[C6 运行](../reports/c6-seed42-epoch1.json)、[C6 对 C3](../reports/c6-vs-c3.json)、[C6 对 C5](../reports/c6-vs-c5.json)。
