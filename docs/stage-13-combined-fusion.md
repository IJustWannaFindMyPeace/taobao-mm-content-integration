# SimTier 与 MAKE 的互补性对照

## 研究问题与控制变量

C3 将目标与历史的内容相似度转成分桶计数；C5 将预训练内容兴趣向量及隐藏层接入 ID 模型。C6 同时使用两种特征，检验统计信息是否能补充已学习的内容兴趣。

C6 使用与 C5 相同的 C1 第二轮检查点并冻结内容分支，使用与 C3 相同的 20 桶计数缓存。数据仍为 1% 用户子集，seed 42、历史长度 200、batch 32，下游训练一轮。预训练轮数来自验证集选择，不使用测试集。

## 实现

公共 ID 表示、MAKE 兴趣及隐藏层投影、SimTier 计数投影在公共 MLP 第一层的激活之前相加，等价于向第一层追加两组特征。两个新增投影均为零初始化；C6 的公共参数和 MAKE 初始参数与 C5 一致。测试验证初始预测一致、两个融合投影可获得梯度，以及冻结内容分支不更新。

新增 `C6` 类位于 `src/make_fusion.py`，配置位于 `configs/c6.json`。统一训练入口分别校验内容检查点与分桶缓存的来源、校验和和历史长度。

```powershell
python scripts/train_c0.py --store <feature-store> --config configs/c6.json --content-checkpoint <c1-run>/epoch-2.pt --hist-cache <simtier-cache> --output-dir <fresh-c6-run>
```

## 比较与解释

- C6 对 C5：固定预训练内容分支及公共主干，检查增加分桶统计的作用。
- C6 对 C3：固定分桶统计及公共主干，检查增加预训练内容分支的作用；后者使用额外预训练计算量。
- 若只优于其中一个单独方案，不能直接称为互补性成立。

比较使用相同行标识的完整验证预测和用户配对 bootstrap。即使组合的点估计较高，也需结合区间、额外计算量和多种子结果解释。当前配置来自前序验证实验，后续仍须使用保留测试集评估最终方案。
