# SimScore：逐行为语义相似度

## 研究动机与方法

SimScore（Similarity Score）将目标商品与各历史商品的多模态表示关系显式提供给推荐模型。[CIKM 2024 §6.1.3](https://arxiv.org/html/2407.19467v1#S6.SS1.SSS3)将其定义为逐历史语义相似度侧信息，未给出完整接入网络。本项目在公共主干上实现以下适配（C7），与 ID 基线及 [Vector](vector-integration.md) 对照。

使用固定 SCL 向量计算目标与各历史商品的余弦相似度，将相似度与有效标记组成二维侧信息，经共享的无偏置线性层投影到 32 维，再加到历史商品的 ID＋类别表示上。目标端保留 ID＋类别表示。融合后的历史同时参与注意力匹配与聚合，使历史表示在聚合前即具有目标依赖性。

投影包含 64 个可学习权重，采用零初始化；在公共参数与输入相同时保持初始基线预测。多模态表示缺失或零范数时，侧信息置为 `[0, 0]`，保留有效历史的 ID 信息；padding 由历史掩码排除。SCL 输入固定，余弦相似度不直接作为注意力权重。有效标记和投影相加均属于本地实现选择。代码见 [side_information.py](../src/side_information.py)。

## 实验协议

与 Vector、ID 基线共享固定 5% 用户队列、数据划分及公共训练设置：训练、验证、测试分别为 3,052,475、768,773、923,211 条曝光；历史窗口 200，短分支 50，batch 256，下游一轮，训练种子 42、2026、3407。完整设置见[公共协议](../configs/shared-downstream-protocol-v1.json)与[数据划分](sampling-and-splits.md)。

## 测试结果

以下为三个训练种子的指标均值。

|方法|AUC ↑|GAUC ↑|LogLoss ↓|
|---|---:|---:|---:|
|ID 基线|0.605518|0.573708|0.391709|
|Vector|0.607706|0.577532|0.391925|
|SimScore|0.617053|0.593142|0.390030|

SimScore 相对 ID 的平均 GAUC 绝对增量为 +0.019434，三个种子的 95% 用户配对 bootstrap 区间均高于零。每项重采样 2000 次，区间条件于固定模型与队列；整体多项比较未做多重校正。与 Vector 的上述对比为指标均值比较，不据此额外宣称专门的配对显著性结论。

证据：[逐模型指标](../reports/final-test-model-metrics.csv) · [配对比较](../reports/final-test-paired-comparisons.csv) · [最终测试报告](final-test-results.md)。

## 分析与局限

在当前适配和训练协议下，SimScore 的三项指标均值均优于 ID 基线及 Vector，支持显式多模态表示关系特征的应用价值。其侧信息投影参数少于 Vector，因此收益不能解释为增加了更多投影参数。

显式关系特征让下游模型直接利用目标与历史的匹配信息，为其效果优势提供合理解释。结论是当前协议下SimScore优于直接向量接入；这不意味着完整多模态表示的其他信息无效，其他结构仍可能更充分地利用它们。

该结论针对固定表示的下游适配，不代表原论文工业网络的数值复刻。早期探索设置与验证结果见[阶段记录](stage-14-side-information.md)，不替代正式测试证据。
