# 两项目研究主线与证据约束

本文件是两个仓库共同的研究主线入口。阶段日志记录过程，本文记录研究问题、对照关系与允许得出的结论；改变实验规模或实现时须同步检查这些关系，不能只追加阶段结果。

最新范围、命名差异及未闭合证据见[2026-09-22 审计](storyline-audit-2026-09-22.md)。

## 研究定位

使用 TAOBAO-MM 的固定内容表示，研究多模态信息如何进入推荐模型，以及如何进一步用于长历史检索与聚合。属于两篇论文下游机制的非官方适配复现，包含额外受控实验；不是原始私有数据、生产网络、编码器训练和线上收益的完整复刻。

来源：[CIKM 2024 §4/§6](https://arxiv.org/html/2407.19467v1)、[MUSE §3–4](https://arxiv.org/html/2512.07216v1)。MUSE 明确沿用前序工作的 SimTier，因此方法衔接有来源依据；MAKE 不属于必须接入 MUSE 的前置模块。

## 项目一：内容存在，不等于内容会被有效使用

|痛点或待检验假设|改进与对照|现有证据及允许结论|
|---|---|---|
|ID 交互信号对低频商品可能不足|C0 ID-only 对 C2 Vector、C7 SimScore、C3 SimTier；训练频次分组|三种子及分组已完成。低频组有收益迹象，不能单凭该结果证明所有收益都由 ID 稀疏性引起；零训练目标频次不等于新商品|
|直接加入高维内容未必有效|C2 逐商品内容融合 → C7 逐行为相似度 → C3 相似度分桶统计|比较表达方式而不是预设逐级提升。C7 在部分指标强于完整组合，保留该结果|
|内容分支与 ID 主干优化需求可能不同|C0/C1 多轮曲线；随机/预训练 × 冻结/联合训练的 MAKE 四组对照|曲线与 seed 42 四组实验已完成。固定策略下预训练有 GAUC 收益，但训练计算量不等，不证明冻结必然更好或 ID 永远只能一轮|
|内容统计与任务适配知识是否互补|C6 对 C3；C6 对 C5，不能只比较 C6 与 C0|三种子 GAUC 配对结果支持当前配置下的互补收益；不能扩展成所有指标、所有人群均改善|

SCL（Semantic-aware Contrastive Learning）提供语义表示的原理作为方法背景保留；公开向量可供下游使用不意味着已复现 SCL 的图文编码器、搜索购买监督、MoCo 或 Triplet 消融。MAKE（Multimodal Knowledge Extractor）的预训练是下游 CTR 内容分支训练，不是 SCL 编码器重训。

## 项目二：内容不仅用于融合，也用于选择和分析历史

|痛点或待检验假设|改进与对照|现有证据及允许结论|
|---|---|---|
|最近历史可能遗漏目标相关行为|R1 内容检索对 R0 最近 K；L1000 另比类目与两种 ID 检索|L200 的 R1−R0 GAUC 差异不明确；L1000 固定增强聚合后，内容检索相对类目/ID 的三种子配对区间为正|
|检索到相关行为后，普通 ID 聚合仍可能利用不足|固定 GSU：R1 TA、R2 TA+SimTier、R3 SA-TA、R4 SA-TA+SimTier、R5 SimTier-only|三种子消融完成。R2−R1、R3−R1 检查独立加入；R4−R2、R4−R3 检查条件增量，不能仅以完整模型对基线归因|
|历史增加是否真的帮助兴趣建模|固定 K=50，分别比较 R1/R4 的 L200 与 L1000|共同协议三个种子完成，普通聚合和完整组合长度收益区间均为正；L50/L500 单种子诊断也已完成，不是工业十万历史实验|
|简单 GSU 是否已足够|G0 内容余弦对 G1/G2/G3 复杂评分，需有效学习路径|尚无本地完整实验，不得把论文结论当作已复现结论；条件项未执行时，只能称采用简单 GSU，不能称证明复杂 GSU 无用|

GSU（General Search Unit）选择历史；ESU（Exact Search Unit）聚合选中历史。TA 是目标注意力，SA-TA（Semantic-Aware Target Attention）在注意力分数中融入内容语义。R5 仅关闭被研究的长历史 ID 聚合，仍有公共目标 ID、短历史及其他特征，不是整个系统 content-only。

## 原论文对照与额外设计的区别

MUSE 表 3 已包含 TA、SimTier、TA+SimTier、SA-TA、SA-TA+SimTier。R1–R5 是这些结构的本地对照，不应描述为我们补出了原文缺失的整套模块消融。三种子、用户配对区间、初始化和公共分支控制、预测一致性检查属于本项目增加的验证。

CIKM 的不同融合方式、MAKE 轮数与低频分析均有原文依据。随机/预训练 × 冻结/联合四组矩阵进一步拆分初始化与继续训练的影响，是本地额外归因实验。它与等计算量实验不同，不能把预训练额外预算的影响排除掉。两个项目都不要求结果严格复制原文排名。

## 跨项目衔接与不能直接比较的部分

**共享数据与表示 → 比较内容融合方式 → 比较训练策略 → 将固定语义用于目标相关历史检索 → 用 SimTier/SA-TA 改善选中历史聚合 → 检查长度和分组表现。**

两项目共用 5% 用户子集、训练/验证/保留测试划分、固定内容向量、train-only ID 词表、缺失及 padding 契约、完整评估口径和相同种子列表。公共实现迁移有预测一致性检查；但该检查只证明特定迁移配置等价，不证明最终 C0 与 R0 或 C6 与 R4 相同。

关键差异必须保留：CIKM SimTier 使用 20 桶原始计数；MUSE 使用参考代码式 22 维 log1p 计数及可学习缩放。MUSE 长分支使用 Top-K 和共同 V 投影；CIKM 内容融合主干及历史输入不同。因此 **C6 → R4 是研究问题的延伸，不是只改一个模块的性能升级链**。跨仓库不能直接相减并归因于 MUSE；主要效果结论来自各自仓库内的受控对照。若需要数值上的单变量桥接，必须另建统一主干与分桶的桥接实验，当前不声称已有。

## 保留的缺口与规模决策

5% 已选定为本轮两个项目共同主规模，下游 batch=256、两类学习率 0.001 已确定。共同协议的内容融合/MUSE 核心三种子，以及 L200/L1000 和类目/ID 检索三种子均完成并审计。原 batch=32 证据与新协议分开。

MAKE 训练策略及轮数诊断、中间历史长度、共同协议分组和最终只读测试入口仍需补齐。原始 DIN/SIM 全结构、TWIN/MISS/复杂 GSU 尚未完成，明确限制结论，不计为已覆盖。最新逐项状态见[收尾清单](completion-checklist.md)，测试仍未评估。

后续每个实验必须说明：回答哪一行问题、固定什么、改变什么、证据产物、不能得出什么结论。出现负向或跨零结果时修改结论，不删实验以保持预设故事。
