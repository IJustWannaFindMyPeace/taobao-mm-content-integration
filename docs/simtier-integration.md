# SimTier：目标相关的相似度统计

## 方法

SimTier 将逐历史内容相似度汇总为分布统计，为点击预测补充整体兴趣与行为频次信息。[CIKM 2024 §4.2](https://arxiv.org/html/2407.19467v1#S4.SS2)提出按相似度区间计数，并将统计向量与其他表示共同输入 MLP。

本项目实现（C3）对固定 SCL 向量进行 L2 归一化，计算目标与历史的余弦相似度，将 `[-1, 1]` 划为 20 个等宽桶，输出原始计数。padding、缺失内容及零范数配对不计数；每条有效配对计数一次，重复行为按记录计数。该特征保留相似度分布及频次，不保留逐商品对应关系、顺序或桶内精确分数。

ID 注意力分支保持不变。20 维计数经无偏置投影映射到 128 维，与原预测网络第一层输出相加后进入 ReLU；该运算等价于拼接统计向量与原 224 维输入后施加对应线性层。新增 2560 个权重采用零初始化，内容向量保持固定。实现见 [simtier.py](../src/simtier.py)。

## 实验结果

使用固定 5% 用户队列、历史窗口 200、短分支 50、batch 256、下游一轮及三个训练种子。配置和数据来源见[公共协议](../configs/shared-downstream-protocol-v1.json)、[划分说明](sampling-and-splits.md)。下表为正式测试均值。

|方法|AUC ↑|GAUC ↑|LogLoss ↓|
|---|---:|---:|---:|
|ID 基线|0.605518|0.573708|0.391709|
|SimTier|0.616165|0.590215|0.390417|

SimTier 的三项指标均值均改善，平均 GAUC 绝对增量为 +0.016506，三个种子的 95% 用户配对 bootstrap 区间均高于零。完整指标、区间及统计口径见[正式测试报告](final-test-results.md)。

结果验证了相似度统计的应用价值：计数显式表达相关行为出现的数量，补充注意力加权聚合的信息。当前 SimScore 的三项指标均值更好；逐行为相似度保留了统计压缩所舍弃的细节，为这一差异提供合理解释。我们复现了 SimTier 相对 ID 的收益方向，但没有复现论文中 SimTier 优于 SimScore 的排名。

## 分桶实现与敏感性

主实现采用 `floor((s+1)N/2)` 并将索引限制到 `0…N−1`，保留两端点和全部有效计数。论文 Algorithm 1 的字面 `ceil` 写法与 `0…N−1` 比较时会遗漏最高区间内部分配对；这不代表原生产代码一定采用同样处理。

已有对照比较主实现、论文伪代码字面实现及保留全部计数的右闭版本。追加测试中，字面实现的单独 SimTier 模型三个种子 GAUC 均下降；右闭版本没有一致优势。因此保留既有完整计数规则，敏感性结果另行归档，不替换冻结主结果。详见[边界协议](post-main-simtier-boundaries-protocol.md)与[追加测试汇总](supplementary-test-results.md)。

本实现使用原始计数，区别于 MUSE 的 log-count 统计。早期验证实验见[阶段 10](stage-10-simtier.md)；当前三种接入方式的比较见[研究主线](research-narrative.md#内容接入方式对照)。
