# 8/9 组补充诊断协议

复用冻结测试预测，补充 CIKM 商品频次 8 组、MUSE 商品频次 9 组和用户历史长度 9 组。这是测试结果已查看后的描述性分析，不是新的盲测或精确还原原论文未公开分组。

分组对象是本次测试中出现的不同商品或用户，不是曝光行。商品按训练集目标曝光次数排序，未在训练目标中出现者为零；用户按输入历史中非 padding 的行为记录数排序，上限 1000，重复商品记录仍分别计数。每种分组按实体排序后等量划分，组间实体数最多相差 1。

同频次、同长度实体按十进制实体 ID 的 SHA256 顺序打破并列，使规则固定且不依赖标签或预测。相同频次可能跨组，尤其零频商品和长度达到 1000 的用户；因此相邻组不保证有不同的频次范围，不能将并列拆组产生的波动解释为频次效应。

频次数值仅来自训练集，但分组的实体全集来自本次测试输入，所以分位边界并非只由训练集确定。明确区分这一点，不将无标签的测试输入分组描述成训练集划分。

CIKM 比较 ID 基线与 SimTier＋MAKE；MUSE 比较固定多模态表示检索下的普通 ID 注意力与完整增强聚合，L 均为 1000。三种子全部保留。报告每组实体数、曝光数、值域、正样本数、AUC、LogLoss 和 GAUC 有效用户覆盖。

商品分组会拆分用户曝光，该组 GAUC 只描述组内曝光，不能冒充该用户完整测试 GAUC；用户长度组不拆分用户，保留用户全部曝光。此轮不新增子组置信区间，不按效果修改分组规则，原固定频次组结果继续保留。相对变化采用带符号差值，LogLoss 改善方向为基线减候选，不用绝对值掩盖退步。
