## 两个项目如何衔接

共同使用 5% 用户队列、固定 SCL 多模态向量、训练构建的 ID 词表、完整用户评估、三个种子以及 batch=256 的单轮下游主协议。MAKE 推荐预训练有独立预算，明确单列。5% 是已选研究规模，不是硬件最大能力的证明。

第一个项目研究如何利用多模态表示，第二个项目将多模态表示用于历史选择并检验后续聚合。SimTier 是方法上的衔接；MAKE 不必成为 MUSE 前置模块。两仓库完整模型同时改变多个模块，不能将最终分数相减解释成单一升级收益。

## 本轮纠正的命名和范围

1. **零轮预训练不是同一对照。** CIKM 图 6(c) 的零轮分支参与联合训练；本地固定冻结轮数扫描的零轮是随机冻结，属于额外控制实验。已有随机联合组保留为论文式零轮参考，不能与随机冻结混称，也不能将固定冻结曲线称为图 6(c) 的直接复刻。
2. **统计实现存在适配。** 本地 CIKM 分支采用 20 桶 floor/clamp 计数；论文算法使用 ceil 表达式。MUSE 分支采用 22 桶及可学习对数变换。它们分别记录，不称逐行等价，也不在已完成结果上静默改动分桶。
3. **基线覆盖尚不完整。** 原始 DIN、TWIN、MISS 未在共同协议完整复现。旧短历史适配结果不能代替原始 DIN；类目/ID 检索对照已完成，但复杂 GSU 对照仍缺失。早期范围表的优先级不代表完成状态。
4. **不能混合新旧协议。** batch=32 的阶段记录属于历史探索；当前主结论使用共同 batch=256 结果。中间长度、训练策略、预训练轮数仅单种子诊断，不冒充三种子验证。

## 尚待完成的研究闭环

- 补充有明确规格的复杂检索受控对照，优先固定归一化的多模态余弦与 ID 余弦融合，并保持同一 ESU。该有限对照只能回答这一融合方式，不能替代全部可学习检索器或 TWIN/MISS。规格、计算成本与梯度边界须在运行前固定。
- 原始 DIN/TWIN/MISS 作为未覆盖基线公开保留。若不追加完整专项复现，最终不得声称重现论文完整基准表。
- 实现只读评估入口，以验证集预测回放确认一致性；冻结模型、配置、权重和预定义比较后才评估保留测试集。
- 最终报告同时展示负向结果、指标冲突、单种子限制和资源开销，不按验证集赢家选择性展示。

原始图文、搜索购买监督和替代表示不可得，因此 SCL 编码器重训、OpenCLIP/I2I 对照、工业线上结果仍为数据受限项。这些限制不因下游结果完成而消失。
