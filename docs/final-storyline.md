# 主实验阶段故事线（历史归档）

> 本文为主测试阶段的历史快照，保留当时的范围与结论，不作为当前完成状态。最新正文见[研究叙事](research-narrative.md)，追加证据见[追加测试结果](supplementary-test-results.md)，第一个项目收尾核验见[收尾审计](content-project-closeout-audit.md)。

本研究完成了两篇论文在公开 TAOBAO-MM 固定多模态向量上的下游适配实验：共同 5% 用户队列、三个训练种子、54 个冻结模型、完整保留测试集和 66 项配对比较。它回答多模态表示如何用于推荐，以及如何进一步用于选择和聚合长历史；不声称完整复刻两篇论文的工业系统或全部基准。

## 一、多模态表示有信息，怎样让推荐模型用好它？

ID embedding（商品编号对应的可训练向量）主要从交互中学习。SCL（Semantic-aware Contrastive Learning，语义感知对比学习）产生的多模态向量提供另一种表示。本项目使用公开固定向量，没有重新训练 SCL 编码器。

|痛点／问题|改进及对照|最终证据|局限|
|---|---|---|---|
|基于 ID 的推荐模型能否从多模态表示中获益？|ID 基线对逐商品多模态融合、逐行为相似度、相似度统计、MAKE 等|五种多模态方法相对 ID 的测试 GAUC 区间均为三种子正向|逐商品融合的平均 LogLoss 反而更差；不能把排序提升等同所有指标提升|
|直接拼接高维向量是否是最有效的使用方式？|比较 Vector、SimScore、SimTier，而非预设依次提高|逐行为相似度的平均测试 GAUC 为 0.593142，ID 基线为 0.573708|不同方法指标排序不同；不能将方案排列当作必然升级顺序|
|多模态分支与 ID 分支的优化需求是否一致？|多轮曲线，随机／预训练 × 冻结／联合四组对照|验证诊断支持当前配置下预训练有用；ID 后续轮次退步|单种子诊断；额外预训练计算量不等；预训练后继续联合在本配置下可优于冻结|
|多模态表示统计和任务知识是否互补？|SimTier＋MAKE 分别对两个单模块|组合相对 ID 的收益稳定；相对统计仅一个测试种子的区间为正，相对 MAKE 为两个|不能沿用验证阶段“两项增量均在三个种子为正”的更强结论|

SimScore 将目标商品与每条历史行为的语义相似度作为侧信息。SimTier 把这些相似度汇总为分桶计数。MAKE（Multimodal Knowledge Extractor，多模态知识提取器）先训练 CTR 多模态分支，再把多模态兴趣和中间特征接入下游模型。这三个方法回答不同的多模态表示利用问题。

MAKE 有两种零轮对照，必须分开：论文式零轮是随机初始化后联合训练；额外控制组是随机初始化后冻结。已有实验包含两者。论文式零轮相对预训练接入的补充分析见[零轮参考报告](shared-paper-zero-reference-v1.md)，不能用随机冻结的较低基线替代论文零轮以放大收益。

低频收益、轮数曲线和训练策略来自验证诊断，不提升为本轮测试已确认的结论。零训练目标曝光也不自动等于全新商品。

## 二、多模态表示不仅帮助融合，还能帮助选择历史

MUSE（Multimodal Search-based framework）采用两阶段历史建模：GSU（General Search Unit，通用搜索单元）先选择与目标有关的行为；ESU（Exact Search Unit，精细搜索单元）再聚合这些行为。它借鉴前序 SimTier 思路，但不要求先接入 MAKE。

|痛点／问题|改进及对照|最终证据|局限|
|---|---|---|---|
|近期历史是否遗漏相关行为？|多模态表示 Top-K 检索对近期历史、类目检索、两种 ID 检索|L1000 固定增强聚合后，多模态表示相对类目／ID 检索的测试区间均为三种子正向|L200 多模态表示对近期历史只有一个种子区间为正，不支持无条件收益|
|选中行为后，普通聚合是否足够？|固定检索，分别加入统计或语义注意力|统计、语义注意力单独加入的测试 GAUC 区间均为三种子正向|已有统计后再加语义注意力的三个区间均跨零|
|更多历史能否转化为收益？|普通聚合和完整聚合各自比较 L200 与 L1000，K 均为 50|两种聚合的三种子区间均为正；完整聚合平均增加 0.003923 GAUC|不是单调长度规律或十万历史验证；L50/L500 仅单种子验证诊断|
|更复杂的检索是否更好？|纯多模态余弦对多模态表示＋商品 ID 等权余弦，保持 ESU 不变|等权融合平均减少 0.004645 测试 GAUC，三个区间均为负，AUC、LogLoss 也变差|只验证这一融合规则，不覆盖可学习评分、TWIN、MISS|

SA-TA（Semantic-Aware Target Attention，语义感知目标注意力）在 ID 注意力分数中加入多模态语义。统计与 SA-TA 单独加入都有用，不等于两者叠加后总有额外收益。L200 的完整聚合相对仅长历史统计，两个种子跨零、一个为负，也必须保留。这里“仅统计”仍含公共 ID 和短历史分支。

完整 L1000 方案的平均测试 GAUC 为 0.595488，但这个数值不能减去第一个项目的最终数值就解释成某一模块的收益；历史范围和结构同时改变了。可归因的证据来自各项目内部的受控比较。

## 三、两个项目为什么仍是一条迭代路径？

第一阶段解决“如何把固定多模态表示用于 CTR”；第二阶段解决“如何用多模态表示从更长历史中挑出行为并建模”。两者共享数据版本、用户队列、可训练词表、指标、训练种子与共同下游协议。方法冲突按 MUSE 主协议适配并记录，MAKE 推荐预训练的独立预算单列。

这条路径的完整性体现为问题、对照和证据连贯，而不是每个新增模块都必须获胜。测试集将 CIKM 组合互补性的证据收窄，也保留了 MUSE 叠加收益不明确和简单融合检索退步的结果；这些结果没有触发重训、调参或替换主表模型。

## 四、实验如何保证可解释？

1. 先完成数据契约、ID 对齐、padding、完整用户评估与资源检查，再确定共同 5% 用户队列和 batch=256。
2. 核心方法使用三个种子；训练策略与中间长度作为明确标注的单种子诊断。共同主表不混入早期 batch=32 的探索结果。
3. 54 组完整验证回放与原预测逐元素一致；在线分桶与原缓存一致。之后冻结权重、代码、数据和 66 项比较，才读取测试结果。
4. 每组评估完整 923,211 条测试曝光；AUC、LogLoss 使用全部记录，GAUC 使用同时存在正负标签的完整用户。区间按用户配对重采样，未作多重校正，三个种子共享同一队列。

最终 18 种方案的三种子主表和全部比较均公开，不仅展示最高分。[多模态融合测试报告](final-test-results.md)；[MUSE 测试报告](https://github.com/IJustWannaFindMyPeace/taobao-mm-muse-repro/blob/main/docs/final-test-results.md)。

## 五、已完成与未覆盖

本轮共同协议的下游适配主实验、验证诊断、冻结回放和保留测试评估已完成。单卡 12 GB 能支持本次范围，不代表已测得最大数据规模；5% 是资源与研究覆盖的折中，不能等同全量数据复现。

仍未覆盖 SCL 原始图文编码器重训、OpenCLIP/I2I 表示对照、原始 DIN/TWIN/MISS 完整基准、其他可学习检索器及工业线上收益。测试集的独立低频分组和训练策略确认也不在本轮冻结比较内。若将来扩展，须作为新研究阶段单列，不能继续使用当前测试结果调参并称其为未见测试。

原文：[CIKM 2024](https://arxiv.org/html/2407.19467v1)；[MUSE](https://arxiv.org/html/2512.07216v1)。论文方法、本地适配和实验观察分别报告。
