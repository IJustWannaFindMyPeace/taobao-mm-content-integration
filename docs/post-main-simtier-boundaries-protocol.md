# SimTier 分桶边界敏感性：固定协议

## 问题与三种口径

[CIKM 2024 Algorithm 1](https://arxiv.org/html/2407.19467v1)写出 `ceil((s+1)/2*N)`，随后与 `range(0,N)` 比较。N=20 时，按字面执行会遗漏相似度 `s>0.9` 的有效行为，含 s=1；浮点边界以实际计算为准。这与正文“将范围分成 N 个桶并计数”的直觉并不完全一致，不能静默修正后称为唯一原实现。

|方案|索引与有效范围|含义|
|---|---|---|
|现有 floor|`floor((s+1)*N/2)`，夹到 0…N−1|保持原冻结主结果|
|paper_literal|`ceil((s+1)*N/2)`，只计 0…N−1|原伪代码字面行为；不把越界项夹回最后桶|
|right_closed|`ceil((s+1)*N/2)-1`，夹到 0…N−1|保留全部计数的右闭区间解释；是明确的本地修正|

三者都使用相同归一化内容向量、相同 padding/缺失 mask、N=20、L200。s=-1 在保留计数版本中归首桶。缺失内容和 padding 不计数，重复行为按位置计数。原始 SCL 编码器不重训。

## 固定实验

在仅 SimTier（C3）和 SimTier＋MAKE（C6）上，各对两种新分桶训练三个种子，共 12 次新训练；同种子的原 floor 模型复用。所有模型维持现有共同下游协议：5% 用户队列、batch=256、单轮、相同初始化和优化器，训练 3,052,475 条曝光、验证 768,773 条曝光。

C6 复用原主实验同种子已选定的内容检查点，完全冻结该选择；本实验不同时更改 MAKE 轮数。训练代码及模型文件保持原样，仅替换经过指纹核验的直方图缓存。

缓存程序逐批重算原 floor，要求与旧缓存逐元素相同；分别报告有效配对数、遗漏配对数、相对 floor 改变的曝光数。right_closed 必须保存全部有效计数。边界测试覆盖 -1、内部精确边界、1、最高区间内部和全 mask 样本。

预先固定 12 项比较：每种子、每个模型分别比较两种新分桶与原 floor。采用 2,000 次用户级配对 bootstrap，条件于已训练模型，无多重校正。不得根据指标选择分桶后覆盖原冻结测试结果。

## 执行与解释

`cache_simtier_boundaries.py` 构建并审计缓存，`run_simtier_boundary_extension.py` 串行训练与比较。源码、配置、数据清单、内容权重和缓存均留存指纹；下游沿用既有资源门槛，超限即停，不自动降低 batch。

实验已完成，缓存、12 次训练、验证与统计共约 90 分钟，见[结果报告](post-main-simtier-boundaries-results.md)。范围是两种模型的验证集敏感性，不是新盲测。paper_literal 的变化包含索引平移、边界归属及计数丢失，不能把其指标变化全部归因于边界；right_closed 更接近考察完整计数下的边界归属影响。
