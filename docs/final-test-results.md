# 最终保留测试集结果

54 个模型和 66 项预先冻结的配对比较全部完成，完整产物摘要复核通过。测试结果未用于调整模型或选择训练检查点。本文表格只展示本项目方法；两仓库的完整机器可读证据一致。

固定 5% 用户队列，测试 923,211 条曝光、82,542 位用户、126,722 条点击。GAUC 有效用户 45,985 位，对应 700,297 条曝光（75.8545%）；其余用户未同时含两类标签，不参与 GAUC，但仍参与全局 AUC 和 LogLoss。

## 三种子指标

GAUC 列为均值 ± 样本标准差；AUC、LogLoss 为均值。标准差仅反映三个训练种子的波动，不是置信区间。

|方法|AUC ↑|GAUC ↑（均值 ± 标准差）|LogLoss ↓|
|---|---:|---:|---:|
|ID 基线|0.605518|0.573708 ± 0.000828|0.391709|
|逐商品多模态融合|0.607706|0.577532 ± 0.001351|0.391925|
|SimTier 相似度统计|0.616165|0.590215 ± 0.000527|0.390417|
|MAKE 预训练冻结接入|0.619105|0.590055 ± 0.001362|0.390042|
|SimTier＋MAKE|0.619468|0.591200 ± 0.001610|0.390150|
|SimScore 逐行为相似度|0.617053|0.593142 ± 0.000351|0.390030|

## 受控比较

差值均为前者减后者的绝对 GAUC 差，不是相对百分比。“正／负／跨零”按 seed=42、2026、3407 排列，表示各自 95% 用户配对区间与零的关系。每项 2000 次重采样，66 项未作多重校正，不能作为严格的确认性显著性清单。

|比较|平均 GAUC 差|三个种子的区间方向|
|---|---:|---|
|逐商品多模态融合 − ID 基线|+0.003824|正／正／正|
|SimTier 相似度统计 − ID 基线|+0.016506|正／正／正|
|MAKE 预训练冻结接入 − ID 基线|+0.016347|正／正／正|
|SimTier＋MAKE − ID 基线|+0.017491|正／正／正|
|SimScore 逐行为相似度 − ID 基线|+0.019434|正／正／正|
|SimTier＋MAKE − SimTier 相似度统计|+0.000985|跨零／正／跨零|
|SimTier＋MAKE − MAKE 预训练冻结接入|+0.001144|正／正／跨零|
|SimScore 逐行为相似度 − SimTier＋MAKE|+0.001942|正／跨零／正|

## 与验证结论的差异

五种多模态融合方式相对 ID 基线的 GAUC 区间在三个种子均为正；但逐商品融合的平均 LogLoss 比 ID 基线更差，收益不能解释为所有指标都改善。

统计＋MAKE 相对统计的测试区间仅一个种子为正，另外两个跨零；相对 MAKE 的两个种子为正、一个跨零。验证阶段两项比较均为三种子正向区间，测试证据明显减弱。因此不能继续写成“两个模块在所有种子都稳定互补”。

逐行为相似度的平均测试 GAUC 高于完整组合，两个种子的配对区间为正、一个跨零；完整组合的平均 AUC 更高。模型排序依赖指标，不能将论文方案包装成必然逐级胜出的路线。

本页保留原主测试范围。MAKE策略与轮数后来已完成[追加测试](supplementary-test-results.md)，低频分组另有明确标注的事后测试诊断；它们不改写本页原冻结比较。

## 证据与边界

三种子共享一个固定用户队列；未覆盖抽样队列变化。5% 用户队列不是全量 TAOBAO-MM，L1000 不是工业十万历史。公开固定 SCL 向量的下游适配不等于 SCL 编码器重训、原始工业网络和线上收益复刻。
