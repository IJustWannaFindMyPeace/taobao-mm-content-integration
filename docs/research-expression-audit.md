# 研究表达审计

日期：2026-10-02。

## 范围与方法

对两个仓库全部 Git 跟踪文件建立清单：内容集成 337 项、MUSE 330 项。对可解码文本（包括文档、报告、生成脚本及 SVG 文本）检索结论、归因和待办表述，复核命中上下文；重点通读 README、研究主线、论文差异分析、方法说明、结果入口及展示计划。历史记录保留时点属性，机器可读结果与执行契约保留原始证据。本轮是研究表达审计，不是重新训练或重新估计统计结果。

## 发现与修订

|问题|处理|
|---|---|
|差异分析反复强调未定位唯一原因，弱化方法结论|明确有效、无增量和退步的结论，机制解释集中表述|
|主线重复列举未排除的边缘因素|保留数据范围、结构适配和影响判断的统计边界|
|机制定位出现在未完成问题清单|明确为可选扩展，不作为完成现有研究的前提|
|图表标题和注释过度强调未作因果证明|以主要发现作标题，保留分组方式和样本范围|
|部分生成脚本仍包含旧措辞|同步相关展示生成源，避免再生成恢复旧表述|

## 表达准则

先给出实验支持的结论，再给出结构或行为层面的合理解释。方法有效无需以穷尽细部机制为前提；机制解释不写成已证明的唯一原因。保留负结果、跨零区间、预算差异、主测试与追加测试时序，以及未覆盖的数据与表示范围。历史阶段的后续计划不自动成为当前任务。

当前证据足以支持两项目的核心研究故事线。本轮未发现需要因表达问题追加训练的事项；后续新实验仅围绕明确的新研究目标安排。公开正文保留研究内容，教学问答留在对话中。

## 验证

重新运行素材证据审计通过：9份来源、12张图、24份图像资产、186条图表数据及11条核心主张对应关系通过核验，两仓库共享展示文件一致。两张修改后的图已检查排版。训练代码、模型权重、原始指标与统计区间未修改。
