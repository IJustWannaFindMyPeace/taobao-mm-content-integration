## 痛点、改进与证据边界

- **内容如何有效融合：**相似度统计与 MAKE 组合相对各自单项，三个种子的 GAUC 配对区间均为正。但逐行为相似度与组合的三个区间均跨零，复杂组合不是已证明的唯一最优方案。直接向量融合存在 GAUC 与 LogLoss 的取舍，完整指标保留。
- **检索到历史之后如何理解：**在内容检索固定时，增加统计分支、单独增加语义注意力的 GAUC 区间三个种子均为正。
- **模块是否必然叠加获益：**已有统计分支后再加入语义注意力，三个种子的 GAUC 区间均跨零；完整组合相对长历史统计分支也均跨零。不能用点估计排名解释稳定胜负或等效。
- **是否已经证明内容检索更好：**L200 下，内容检索与最近历史的 GAUC 差异三个种子均跨零。此结果不替代 L1000 的历史长度对照，也不替代固定增强聚合下的类目/ID 检索对照。

故事线保留研究问题及可检验的改进假设，不预设每一环必须提升。下一阶段研究更长候选历史及独立检索策略；MAKE 训练策略专项对照和最终测试也仍需完成。

## 审计与解释限制

核验完整预测的源行、用户和标签，重算指标，与训练报告一致；检查训练步数、配置计划、同项目公共源码，以及 MAKE 检查点和直方图缓存的一致性。检查点存在，训练报告的重载误差为零，本次没有重新加载全部权重。

每项 GAUC 配对区间基于 2000 次用户 bootstrap，条件于固定模型和队列；单标签用户的 GAUC 权重为零。15 项比较未做多重校正，三个种子也不等于对不同人群的独立复现。训练协议曾使用该验证集选择，不能把结果称为独立测试结论。
