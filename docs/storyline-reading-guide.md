# 从多模态表示到长历史兴趣：结果阅读指南

正文入口已整理为[研究叙事](research-narrative.md)，配套[论文对照与分析](paper-comparison-and-analysis.md)、[展示计划](presentation-plan.md)和[图表](storyline-figures.md)。本页保留阅读与状态索引。


两个项目回答同一个逐步深入的问题：给定目标广告，如何利用用户过去的行为预测点击？第一项目研究多模态信息怎样进入模型，第二项目研究怎样从更长历史中选择并聚合相关信息。

这条路径不是每加一个模块都提高分数。实验的价值是把有效改进、无明确增益和失败尝试分开，并说明证据支持到哪里。

## 1. 先建立基准：只用交互学习到的 ID 表示

ID embedding 是由交互训练得到的编号向量。它能学习协同偏好，但低频商品的交互监督较少。因此引入固定多模态向量，让模型获得另一类信息。本项目使用公开向量，没有重新训练生成这些向量的 SCL 编码器。

这里要先区分两层学习：上游编码器产生多模态向量；下游推荐模型学习怎样使用向量预测点击。向量固定，不代表下游不需要训练。

## 2. CIKM：有了多模态表示，怎样用才有效？

|方法|它给下游提供什么|我们检验的问题|
|---|---|---|
|Vector，向量接入|逐商品多模态特征|直接提供向量能否优于仅 ID？|
|SimScore，相似度分数|目标与各条历史的语义相似度|显式提供相关性是否更容易利用？|
|SimTier，相似度分桶统计|各相似度区间的行为数量|舍弃具体物品身份与顺序后，统计分布是否仍有价值？|
|MAKE，多模态知识提取器|预训练多模态分支的兴趣与中间特征|先学习使用多模态表示，再接入 ID 模型是否有帮助？|

主测试中，这些多模态方案相对 ID 基线的 GAUC 都有三种子正向配对区间。例如仅 ID 的平均测试 GAUC 为 0.573708，SimScore 为 0.593142。这个结果支持多模态信息有用，但不同方法不是预先排好的升级顺序；某些排序改善伴随 LogLoss 变差。

MAKE 的动机是两类参数的训练需求可能不同。我们既比较随机/预训练与冻结/联合策略，也补齐了三个种子的 0、1、3、5 轮对照。零轮必须是随机初始化后联合训练；随机冻结是另外一个控制。结果不支持“预训练越久越好”，而且正轮冻结与零轮联合同时改变初始化和冻结策略，不能称纯轮数效应。

SimTier 另做了分桶敏感性检查：原伪代码字面实现会遗漏最高相似度区间的一些计数；保留计数的右闭解释也没有稳定全面胜过既有实现。因此实现差异需要报告，不能按分数挑一种解释后称为唯一原版。

## 3. 从 CIKM 到 MUSE：多模态表示还可以决定看哪些历史

MUSE 是多模态搜索式终身兴趣建模框架。它把历史处理分成两步：

- GSU（General Search Unit，通用搜索单元）：针对当前目标，从较长历史中筛选候选行为。
- ESU（Exact Search Unit，精细搜索单元）：进一步计算被选中行为的贡献并聚合兴趣。

所以两个项目的衔接是：先证明多模态表示可以作为推荐信息，再研究它能否帮助选择与理解历史。MUSE 不要求先串联一个 MAKE 模块；共享的是多模态表示、数据与研究问题，不是机械地把所有组件堆起来。

在同一增强聚合结构、历史上限1000下，多模态检索相对类目和两种 ID 检索的测试 GAUC 差值均有三种子正向区间。但在历史上限200时，多模态检索对近期历史的增益不稳定，不能说目标相关搜索在所有条件下必胜。

## 4. 选得相关，还要检验如何聚合

SA-TA（Semantic-Aware Target Attention，语义感知目标注意力）把多模态语义引入 ID 注意力评分。SimTier 提供相似度分布统计，两者提供的信息不同。

固定多模态表示检索后，单独加入统计、单独加入语义注意力，都有三种子正向测试证据。但是已有统计后再加入语义注意力，三个差值区间均跨零。两个模块分别有用，不意味着叠加后的增量必然明确。

## 5. 历史越长、评分越复杂，是否越好？

长度实验保持 K=50，只扩大可供检索的历史上限。完整 MUSE 的验证曲线从50到200、从200到500，三个种子均有正向区间；500到1000均跨零。追加测试中，前两段仍均为三个种子正向，500到1000变为两个跨零、一个正向；验证与测试须分别报告。

复杂检索也未必更好：固定多模态表示与 ID 等权余弦融合在主测试中退步；G1 的两阶段学习后多模态检索在三个种子的验证与追加测试上均不如原多模态余弦；G3 的共享融合评分有明显种子差异，追加测试一个跨零、两个负向。这些负结果限定于具体实现，不能扩大成所有学习式检索都无效。

DIN、TWIN、MISS 的本地适配用来拓展比较视角。DIN 使用短历史；TWIN 保留多头一致评分；MISS 保留协同与多模态表示双路。它们的输入预算和结构不同，原验证表及追加测试表帮助阅读，但不是严格等预算的因果比较。

## 6. 阅读指标与结果时的四条规则

1. AUC/GAUC 衡量排序，LogLoss 衡量概率预测损失；一个提高不保证另一个改善。注意力、检索相似度都不是 pCTR。
2. 差值区间跨零表示当前证据不足以明确方向，不表示等效，也不表示没有任何作用。区间条件于已训练模型，未作多重比较校正。
3. 主实验54个模型与66项比较使用冻结测试；审计后73份补充检查点已完成追加测试、93项比较全部归档，发生在主测试已查看之后；测试重新分组属于事后分析。不能混成同一个盲测榜单。
4. 使用同一5%用户队列和三个种子，有助于控制比较，但没有测量数据抽样变化。单卡12GB完成这套实验，不等于已完成全量或找到显卡最大规模。
